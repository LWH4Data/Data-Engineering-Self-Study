<h1>1. 사용자 위치 얻기</h1>
<ul>
  <li>
    앱에서 사용자의 위치를 얻는 방법은 <strong>플랫폼 API</strong>를 이용하는 방법과 <strong>구글 Play 서비스에서 제공하는 라이브러리</strong>를 이용하는 방법 두 가지가 있다.
  </li>
</ul>

<br>

<h2>1-1. 위치 접근 제한</h2>
<ul>
  <li>
    앱에서 사용자의 위치를 추적하기 위해서는 하단의 3가지 권한이 필요하며 상황에 맞추어 <strong>매니페스트 파일에 권한을 등록</strong>해야 한다.
  </li>
    <ul>
      <li>
        android.permission.ACCESS_COARSE_LOCATION
      </li>
        <ul>
          <li>
            <strong>와이파이</strong>나 <strong>모바일(또는 둘 다)</strong>를 사용해 기기의 위치에 접근하는 권한이다.
          </li>
          <li>
            도시에서 <strong>1블록</strong> 정도의 오차 수준이다.
          </li>
        </ul>
      <li>
        android.permission.ACCESS_FINE_LOCATION
      </li>
        <ul>
          <li>
            위성, 와이파이, 모바일 데이터 등 이용할 수 있는 위치 제공자를 사용해 <strong>최대한 정확한 위치</strong>에 접근하는 권한이다.
          </li>
        </ul>
      <li>
        android.permission.ACCESS_BACKGROUND_LOCATION
      </li>
        <ul>
          <li>
            안드로이드 10(API 레벨 29) 이상에서 <strong>백그라운드 상태</strong>에서 위치에 접근하는 권한이다.
          </li>
        </ul>
    </ul>
  <li>
    ACCESS_COARSE_LOCATION과 ACCESS_FINE_LOCATION은 앱에서 <strong>얼마나 정확한 위치</strong>가 필요한가를 기준으로 선택한다.
  </li>
    <ul>
      <li>
        안드로이드 12(API 레벨 31) 버전부터는 android.permission.ACCESS_FINE_LOCATION을 등록하려면 <strong>android.permission.ACCESS_COARSE_LOCATION을 같이 등록</strong>해 주어야 한다.
      </li>
    </ul>
  <li>
    서비스 컴포넌트에서 위치에 접근하려면 <strong>foregroundServiceType 속성</strong>에 <strong>"location"</strong>을 지정해 주어야 한다.
  </li>
</ul>

```xml
<!-- 1. 서비스에서 위치 접근-->
<!--   - foregroundServiceType에 "location"을 지정한다.-->
<service
    android:name="MyNavigationService"
    android:foregroundServiceType="location"
    (... 생략 ...)>
</service>
```

<h2>1-2. 플랫폼 API의 위치 매니저</h2>
<ul>
  <li>
    플랫폼 API를 이용해 사용자의 위치를 얻을 때에는 <strong>LocationManager</strong>라는 시스템 서비스를 이용한다.
  </li>
</ul>

```kotlin
// 1. 플랫폼 API를 이용하기 위해 LocationManager 시스템 서비스 이용.
val manager = getSystemService(LOCATION_SERVICE) as LocationManager
```

<h3>1-2-1. 위치 제공자 지정하기</h3>
<ul>
  <li>
    사용자의 위치를 얻기 위해서는 먼저 <strong>위치 제공자(location provider)</strong>를 구해야 한다.
  </li>
  <li>
    위치 제공자에는 GPS, 이동 통신망, 와이파이 등 여러 가지가 있다.
  </li>
    <ul>
      <li>
        GPS: GPS 위성을 이용한다.
      </li>
      <li>
        Network: 이동 통신망을 이용한다.
      </li>
      <li>
        Wifi: 와이파이를 이용한다.
      </li>
      <li>
        Passive: 다른 앱에서 이용한 마지막 위치 정보를 이용한다.
      </li>
    </ul>
  <li>
    현재 기기에 어떤 위치 제공자가 있는지 알고 싶다면 LocationManager의 <strong>allProviders 프로퍼티</strong>를 이용한다.
  </li>
    <ul>
      <li>
        allProviders는 <strong>MutableList&ltString&gt 타입의 결과</strong>를 반환한다.
      </li>
    </ul>
  <li>
    지금 사용할 수 있는 위치 제공자를 알아볼 때에는 <strong>getProviders() 함수</strong>를 이용한다.
  </li>
</ul>

```kotlin
// 1. 모든 위치 제공자 알아보기.
var result = "All Providers : "

// allProviders 프로퍼티를 사용한다.
val providers = manager.allProviders
for (provider in providers) {
    result += "$provider, "
}

// All Providers : passive, gps, network
Log.d("kkang", result)
```

```kotlin
// 2. 지금 사용할 수 있는 위치 제공자 알아보기.
result = "Enabled Providers : "

// getProviders() 함수를 이용한다.
val enabledProviders = manager.getProviders(true)
for (provider in enabledProviders) {
    result += "$provider, "
}

// Enabled Providers : passive, gps, network
Log.d("kkang", result)
```

<h3>1-2-2. 위치 정보 얻기</h3>
<ul>
  <li>
    사용자의 위치 정보를 얻을 때에는 LocationManager의 <strong>getLastKnownLocation() 함수</strong>를 이용한다.
  </li>
    <ul>
      <li>
        getLastKnownLocation() 함수의 반환값은 <strong>Location</strong>이고 만약 <strong>널값</strong>이라면 위치를 가져오는데 <strong>실패</strong>한 것이다.
      </li>
      <li>
        Location은 위치의 정확도, 위도, 경도, 획득 시간 등의 데이터를 포함하는 객체이다.
      </li>
        <ul>
          <li>
            getAccuracy(): 정확도
          </li>
          <li>
            getLatitude(): 위도
          </li>
          <li>
            getLongitude(): 경도
          </li>
          <li>
            getTime(): 획득 시간
          </li>
        </ul>
    </ul>
  <li>
    계속 위치를 가져와야 한다면 <strong>LocationListener</strong>를 이용하며 다음과 같은 상황일 때 호출된다.
  </li>
    <ul>
      <li>
        onLocationChanged(): 새로운 위치를 가져오면 호출된다.
      </li>
      <li>
        onProviderEnabled(): 위치 제공자가 이용할 수 있는 상황이면 호출된다.
      </li>
      <li>
        onProviderDisabled(): 위치 제공자가 이용할 수 없는 상황이면 호출된다.
      </li>
    </ul>
  <li>
    LocationListener 인터페이스에서 <strong>onLocationChanged()</strong>는 추상 함수로 꼭 재정의가 되어야 하지만 onProviderEnabled()와 onProviderDisabled() 함수는 필요에 따라 재정의한다.
  </li>
  <li>
    LocationManager의 <strong>requestLocationUpdates()</strong> 함수로 등로갛면 위치를 계속 가져올 수 있다.
  </li>
    <ul>
      <li>
        더이상 위치 정보가 필요없다면 <strong>removeUpdates()</strong> 함수로 해제한다.
      </li>
    </ul>
  <li>
    requestLocationUpdates() 함수의 두 번째 매개변수는 <strong>위치 전달 주기</strong>이며 <strong>밀리초 단위</strong>로 설정한다.
  </li>
    <ul>
      <li>
        세 번째 매개변수는 <strong>거리</strong>가 얼마만큼 변경되었을 때 위치를 전달받을지 <strong>미터 단위</strong>로 설정한다.
      </li>
    </ul>
</ul>

```kotlin
// 1. 위치 한 번만 가져오기.
if (ContextCompat.checkSelfPermission(
    this, android.Manifest.permission.ACCESS_FINE_LOCATION
    ) === PackageManager.PERMISSION_GRANTED
)  {
  val location: Location? =
      // getLastKnownLocation()을 통해 사용자의 위치 정보를 얻는다.
      manager.getLastKnownLocation(LocationManager.GPS_PROVIDER)
  location?.let {
      val latitude = location.latitude
      val longitude = location.longitude
      val accuracy = location.accuracy
      val time = location.time

      Log.d("kkang", "$latitude, $longitude, $accuracy, $time")
  }
}
```

```kotlin
// 2. 위치 계속 가져오기.
//   - LocationListener 사용.
val listener: LocationListener = object : LocationListener {
    override fun onLocationChanged(location: Location) {
        Log.d("kkang", "${location.latitude}, ${location.longitude}, ${location.accuracy}")
    }

    override fun onProviderDisabled(provider: String) {
        super.onProviderDisabled(provider)
    }
 
    override fun onProviderEnabled(provider: String) {
        super.onProviderEnabled(provider)
    }
}
manager.requestLocationUpdates(LocationManager.GPS_PROVIDER, 
    
    // 위치 전달 주기 (10초)
    10_000L, 
    
    // 거리가 얼마나 떨어지면 위치를 전달받을지 (10m)
    10f, 
    listener)
(... 생략 ...)
manager.removeUpdates(listener)
```

<h2>1-3. 구글 Play 서비스의 위치 라이브러리</h2>
<ul>
  <li>
    위치를 얻을 때 고려해야할 사항들에는 주로 다음이 있다.
  </li>
    <ul>
      <li>
        전력을 적게 소비하는가?
      </li>
      <li>
        정확도는 높은가?
      </li>
      <li>
        API가 간단한가?
      </li>
      <li>
        부가 기능을 제공하는가?
      </li>
      <li>
        대부분 안드로이드 기기를 지원하는가?
      </li>
    </ul>
  <li>
    위처럼 고려할 사항이 많기 때문에 구글에서는 최적의 알고리즘으로 위치 제공자를 지정할 수 있도록 <strong>Fused Location Provider 라이브러리</strong>를 제공한다.
  </li>
    <ul>
      <li>
        라이브러리를 사용하기 위해서는 implementation("com.google.android.gms:play-services:12.0.1")을 선언한다.
      </li>
    </ul>
  <li>
    Fused Location Provider의 핵심 클래스는 <strong>위치 정보</strong>를 얻는 <strong>FusedLocationProviderClient</strong>와 위치 제공자 준비 등 <strong>다양한 콜백</strong>을 제공하는 <strong>GoogleApiClient</strong>가 있다.
  </li>
    <ul>
      <li>
        GoogleApiClient에서 위치 정보 제공자를 결정하면 이를 이용해 FusedLocationProviderClient에서 위치를 가져오는 구조이다.
      </li>
      <li>
        두 클래스를 초기화할 때에는 GoogleApiClient에서는 <strong>GoogleApiClient.ConnectionCallbacks</strong>와 <strong>GoogleApiClient.OnConnectionFailedListener</strong> 인터페이스를 구현한 객체를 지정한다.
      </li>
    </ul>
  <li>
    FusedLocationProviderClient는 하단의 코드 확인.
  </li>
</ul>

```kotlin
// 1. GoogleApiClient 초기화.
val connectionCallback=object: GoogleApiClient.ConnectionCallbacks {
    
    // GoogleApiClient가 Google Play 서비스에 성공적으로 연결되면 호출된다.
    override fun onConnected(p0: Bundle?) {
        // 위치 제공자를 사용할 수 있을 때
        // 위치 획득
    }
    
    // Google Play 서비스와의 연결이 일시적으로 끊기면 호출된다.
    override fun onConnectionSuspended(p0: Int) {
        // 위치 제공자를 사용할 수 없을 때
    }
}

val onConnectionFailedCallback = object : GoogleApiClient.OnConnectionFailedListener {
  
   // Google Play 서비스에 연결하려는 시도가 실패하면 호출된다.
  override fun onConnectionFailed(p0: ConnectionResult) {
    // 사용할 수 있는 위치 제공자가 없을 때
  }
}

val apiClient: GoogleApiClient = GoogleApiClient.Builder(this)
    .addApi(LocationServices.API)
    .addConnectionCallbacks(connectionCallback)
    .addOnConnectionFailedListener(onConnectionFailedCallback)
    .build()
```

```kotlin
// 2. FusedLocationProviderClient 초기화.
val providerClient: FusedLocationProviderClient = LocationServices.getFusedLocationProviderClient(this)
```

```kotlin
// 3. 위치 제공자를 요청한다.
//   - 여러 가지 상황을 고려해 가장 알맞는 위치 제공자를 선택하여 onConnect() 함수를 호출해준다.
apiClient.connect()
```

```kotlin
// 4. 사용자 위치 얻기.
//    - 가장 적절한 위치 제공자를 알아서 선택하기 때문에 FusedLocationProviderClient의
//      getLastLocation() 함수만 호출하면 된다.
override fun onConnected(p0: Bundle?) {
    if (ContextCompat.checkSelfPermission(this@FusedActivity, android.Manifest.permission.ACCESS_FINE_LOCATION
    ) === PackageManager.PERMISSION_GRANTED
  ) {
      // getLastLocation() 함수로 위치를 가져온다.
      //   - addOnSuccessListener() 함수에 등록한 OnSuccessListener를 
      //     구현한 객체 onSuccess() 함수가 호출되면서 전달된다.
      providerClient.getLastLocation().addOnSuccessListener(
          this@FusedActivity,
          object : OnSuccessListener<Location> {
              override fun onSuccess(location: Location?) {
                  val latitude = location?.latitude
                  val longitude = location?.longitude
              }
          })
    }
} 
```

<h2>2-1. 지도 사용하기</h2>
<ul>
  <li>
    지도를 사용하기 위해서는 의존성을 선언하고, 퍼미션을 등록한 뒤 구글 지도 API를 이용하는 키를 등록해야 한다.
  </li>
    <ul>
      <li>
        의존성은 implementation("com.google.android.gms:play-services:12.0.1")로 선언한다.
      </li>
    </ul>
</ul>

```xml
<!-- 1. 퍼미션 등록 -->
<uses-permission android:name="android.permission.INTERNET"/>
```

```xml
<!-- 2. 구글 지도 API 키 등록 -->
<application ... 생략 ...>
    <!-- 안드로이드 앱에서 apache 라이브러리를 이용한 HTTP 통신을 허용하는 설정. -->
    <!--   - 안드로이드 9버전부터 앱에서 기본으로 이용할 수 없어 설정을 해야한다. -->
    <uses-library android:name="org.apache.http.legacy" android:required="false" />

    <!-- maps.v2.API_KEY의 value에는 지도 API 키를 등록한다. -->
    <meta-data android:name="com.google.android.maps.v2.API_KEY"
        android:value="###구글 지도 API 키 등록###" />
    
    <!-- gms.version은 버전 정보이기 때문에 value에 버전 정보를 지정한다. -->
    <meta-data android:name="com.google.android.gms.version"
        android:value="@integer/google_play_services_version" />
</application>
```

<h2>2-3. 지도 제어하기</h2>
<ul>
  <li>
    사용자의 위치를 중시믕로 지도를 보여 주고 마커를 표시하는 등 <strong>사용자 이벤트</strong>를 처리하기 위해서는 <strong>지도를 제어하는 코드</strong>를 작성해야 한다.

<h3>2-3-1. 지도의 중심 이동하기</h3>
<ul>
  <li>
    지도가 표시하는 지점을 이동하기 위해서는 먼저 지도를 출력하는 뷰 객체를 얻어야 한다.
  </li>
    <ul>
      <li>
        play-services 라이브러리가 제공하는 프래그먼트에서 GoogleMap 클래스이다.
      </li>
    </ul>
</ul>

```kotlin
// 1. 지도 뷰 객체 얻기.
//   - OnMapReadyCallback을 구현한 객체를 
class MapActivity : AppCompatActivity(), OnMapReadyCallback {
    lateinit var binding. ActivityMapBinding
    var googleMap: GoogleMap? = null

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedinstanceState)
        binding = ActivityMapBinding.inflate(layoutInflater)
        setContentView(binding.root)
        // SupportMapFragment의 getMapAsync() 함수에 전달하면 지도 객체를 이용할 수 있을 때 onMapReady() 함수가 자동 호출되며
        // GoogleMap 객체를 전달한다.
        (supportFragmentManager.findFragmentById(R.id.mapView) as SupportMapFragment?)!!.getMapAsync(this)
    }

    override fun onMapReady(p0: GoogleMap?) {
        googleMap = p0
    }
}
```

```kotlin
// 2. 지도의 중심 이동.

// 지도에서 한 지점의 위도와 경도는 LatLng로 표현한다.
val latLng = LatLng(37.566610, 126.978403)

// 지도의 중심 이동은 CameraPosition 객체를 이용한다.
val position = CameraPosition.Builder()
    
    // target() 함수로 위치를
    .target(latLng)
    
    // zoom() 함수로 확대 수준을 지정한다.
    .zoom(16f)
    .build()

// CameraPosition 객체를 GoogleMap 객체의 moveCamera() 함수와 전달하면 지정한 대로 지도의 중심이 이동한다.
googleMap?.moveCamera(CameraUpdateFactory.newCarmeraPosition(position))
```

<h3>2-3-2. 마커 표시하기</h3>
<ul>
  <li>
    지도에 마커를 표시하려면 Bitmap 객체가 필요한데 개발자가 직접 준비한 이미지나 play-service에서 제공하는 이미지를 이용할 수도 있다.
  </li>
</ul>

```kotlin
// 1. 마커 표시하기.

// 마커 옵션
//   - 마커 정보를 MarkerOptions에 담는다.
val markerOptions = MarkerOptions()

// 마커에 출력할 이미지를 icon() 함수로 전달한다.
markerOptions.icon(BitmapDescriptorFactory.fromResource(R.drawable.ic_marker))

// 출력할 이미지의 위치를 position() 함수로 지정한다.
markerOptions.position(latLng)

// title()과 snippet()은 선택 옵션으로 마커를 클릭했을 때 풍선 도움말로 표시하는 정보이다.
markerOptions.title("서울시청")
markerOptions.snippet("Tel:01-120")

// 마커 표시하기.
//   - 저장한 마커의 정보를 GoogleMap의 addMarker() 함수에 전달하여 마커를 표시한다.
googleMap?.addMarker(markerOptions)
```

<h3>2-3-3. 지도에서 사용자 이벤트 처리</h3>
<ul>
  <li>
    사용자 이벤트가 발생하면 앱에서 감지해 처리할 수 있도록 다음 <strong>인터페이스</strong>를 제공한다.
  </li>
    <ul>
      <li>
        GoogleMap.OnMapClickListener: 지도 클릭 이벤트
      </li>
      <li>
        GoogleMap.OnMapLongClickListener: 지도 롱 클릭 이벤트
      </li>
      <li>
        GoogleMap.OnMarkerClickListener: 마커 클릭 이벤트
      </li>
      <li>
        GoogleMap.OnMarkerDragListener: 마커 드래그 이벤트
      </li>
      <li>
        GoogleMap.OnInfoWindowClickListener: 정보 창 클릭 이벤트
      </li>
      <li>
        GoogleMap.OnCameraIdleListener: 지도 화면 변경 이벤트
      </li>
    </ul>
</ul>

```kotlin
// 1. 지도 이벤트 핸들러.

// 지도 클릭 이벤트
googleMap?.setOnMapClickListener { latLng ->
    Log.d("kkang", "click" : ${latLng.latitude}, ${latLng.longitude}")
}

// 지도 롱 클릭 이벤트
googleMap?.setOnMapLongClickListener { latLng ->
    Log.d("kkang", "long click" : ${latLng.latitude}, ${latLng.longitude}")
}


// 지도 화면 변경 이벤트
googleMap?.setOnCarmeraIdleListener {
    val position = googleMap!!.cameraPosition
    val zoom = position.zoom
    val latitude = position.target.latitude
    val longitude = position.target.longitude
    Log.d("kkang", "user change : $zoom, $latitude, $longitude")
}

// 마커 클릭 이벤트
googleMap?.setOnMarkerClickListener { marker -> 
    true
}

}
```
