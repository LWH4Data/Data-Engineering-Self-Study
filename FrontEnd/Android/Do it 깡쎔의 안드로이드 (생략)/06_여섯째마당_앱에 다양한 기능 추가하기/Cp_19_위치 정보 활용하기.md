<h1>1. 사용자 위치 얻기</h1>
<ul>
  <li>
    앱에서 사용자의 위치를 얻는 방법은 <strong>플랫폼 API</strong>를 이용하는 방법과 <strong>구글 Play 서비스에서 제공하는 라이브러리</strong>를 이용하는 방법 두 가지가 있다.
  </li>
</ul>

<br>

<h2>1-1. 위치 접근 제한</h2>
<ul>
  <li>
    앱에서 사용자의 위치를 추적하기 위해서는 하단의 3가지 권한이 필요하며 상황에 맞추어 <strong>매니페스트 파일에 권한을 등록</strong>해야 한다.
  </li>
    <ul>
      <li>
        android.permission.ACCESS_COARSE_LOCATION
      </li>
        <ul>
          <li>
            <strong>와이파이</strong>나 <strong>모바일(또는 둘 다)</strong>를 사용해 기기의 위치에 접근하는 권한이다.
          </li>
          <li>
            도시에서 <strong>1블록</strong> 정도의 오차 수준이다.
          </li>
        </ul>
      <li>
        android.permission.ACCESS_FINE_LOCATION
      </li>
        <ul>
          <li>
            위성, 와이파이, 모바일 데이터 등 이용할 수 있는 위치 제공자를 사용해 <strong>최대한 정확한 위치</strong>에 접근하는 권한이다.
          </li>
        </ul>
      <li>
        android.permission.ACCESS_BACKGROUND_LOCATION
      </li>
        <ul>
          <li>
            안드로이드 10(API 레벨 29) 이상에서 <strong>백그라운드 상태</strong>에서 위치에 접근하는 권한이다.
          </li>
        </ul>
    </ul>
  <li>
    ACCESS_COARSE_LOCATION과 ACCESS_FINE_LOCATION은 앱에서 <strong>얼마나 정확한 위치</strong>가 필요한가를 기준으로 선택한다.
  </li>
    <ul>
      <li>
        안드로이드 12(API 레벨 31) 버전부터는 android.permission.ACCESS_FINE_LOCATION을 등록하려면 <strong>android.permission.ACCESS_COARSE_LOCATION을 같이 등록</strong>해 주어야 한다.
      </li>
    </ul>
  <li>
    서비스 컴포넌트에서 위치에 접근하려면 <strong>foregroundServiceType 속성</strong>에 <strong>"location"</strong>을 지정해 주어야 한다.
  </li>
</ul>

```xml
<!-- 1. 서비스에서 위치 접근-->
<!--   - foregroundServiceType에 "location"을 지정한다.-->
<service
    android:name="MyNavigationService"
    android:foregroundServiceType="location"
    (... 생략 ...)>
</service>
```

<br>

<h2>1-2. 플랫폼 API의 위치 매니저</h2>
<ul>
  <li>
    플랫폼 API를 이용해 사용자의 위치를 얻을 때에는 <strong>LocationManager</strong>라는 시스템 서비스를 이용한다.
  </li>
</ul>

```kotlin
// 1. 플랫폼 API를 이용하기 위해 LocationManager 시스템 서비스 이용.
val manager = getSystemService(LOCATION_SERVICE) as LocationManager
```

<h3>1-2-1. 위치 제공자 지정하기</h3>
<ul>
  <li>
    사용자의 위치를 얻기 위해서는 먼저 <strong>위치 제공자(location provider)</strong>를 구해야 한다.
  </li>
  <li>
    위치 제공자에는 GPS, 이동 통신망, 와이파이 등 여러 가지가 있다.
  </li>
    <ul>
      <li>
        GPS: GPS 위성을 이용한다.
      </li>
      <li>
        Network: 이동 통신망을 이용한다.
      </li>
      <li>
        Wifi: 와이파이를 이용한다.
      </li>
      <li>
        Passive: 다른 앱에서 이용한 마지막 위치 정보를 이용한다.
      </li>
    </ul>
  <li>
    현재 기기에 어떤 위치 제공자가 있는지 알고 싶다면 LocationManager의 <strong>allProviders 프로퍼티</strong>를 이용한다.
  </li>
    <ul>
      <li>
        allProviders는 <strong>MutableList&ltString&gt 타입의 결과</strong>를 반환한다.
      </li>
    </ul>
  <li>
    지금 사용할 수 있는 위치 제공자를 알아볼 때에는 <strong>getProviders() 함수</strong>를 이용한다.
  </li>
</ul>

```kotlin
// 1. 모든 위치 제공자 알아보기.
var result = "All Providers : "

// allProviders 프로퍼티를 사용한다.
val providers = manager.allProviders
for (provider in providers) {
    result += "$provider, "
}

// All Providers : passive, gps, network
Log.d("kkang", result)
```

```kotlin
// 2. 지금 사용할 수 있는 위치 제공자 알아보기.
result = "Enabled Providers : "

// getProviders() 함수를 이용한다.
val enabledProviders = manager.getProviders(true)
for (provider in enabledProviders) {
    result += "$provider, "
}

// Enabled Providers : passive, gps, network
Log.d("kkang", result)
```

<h3>1-2-2. 위치 정보 얻기</h3>
<ul>
  <li>
    사용자의 위치 정보를 얻을 때에는 LocationManager의 <strong>getLastKnownLocation() 함수</strong>를 이용한다.
  </li>
    <ul>
      <li>
        getLastKnownLocation() 함수의 반환값은 <strong>Location</strong>이고 만약 <strong>널값</strong>이라면 위치를 가져오는데 <strong>실패</strong>한 것이다.
      </li>
      <li>
        Location은 위치의 정확도, 위도, 경도, 획득 시간 등의 데이터를 포함하는 객체이다.
      </li>
        <ul>
          <li>
            getAccuracy(): 정확도
          </li>
          <li>
            getLatitude(): 위도
          </li>
          <li>
            getLongitude(): 경도
          </li>
          <li>
            getTime(): 획득 시간
          </li>
        </ul>
    </ul>
  <li>
    계속 위치를 가져와야 한다면 <strong>LocationListener</strong>를 이용하며 다음과 같은 상황일 때 호출된다.
  </li>
    <ul>
      <li>
        onLocationChanged(): 새로운 위치를 가져오면 호출된다.
      </li>
      <li>
        onProviderEnabled(): 위치 제공자가 이용할 수 있는 상황이면 호출된다.
      </li>
      <li>
        onProviderDisabled(): 위치 제공자가 이용할 수 없는 상황이면 호출된다.
      </li>
    </ul>
  <li>
    LocationListener 인터페이스에서 <strong>onLocationChanged()</strong>는 추상 함수로 꼭 재정의가 되어야 하지만 onProviderEnabled()와 onProviderDisabled() 함수는 필요에 따라 재정의한다.
  </li>
  <li>
    LocationManager의 <strong>requestLocationUpdates()</strong> 함수로 등로갛면 위치를 계속 가져올 수 있다.
  </li>
    <ul>
      <li>
        더이상 위치 정보가 필요없다면 <strong>removeUpdates()</strong> 함수로 해제한다.
      </li>
    </ul>
  <li>
    requestLocationUpdates() 함수의 두 번째 매개변수는 <strong>위치 전달 주기</strong>이며 <strong>밀리초 단위</strong>로 설정한다.
  </li>
    <ul>
      <li>
        세 번째 매개변수는 <strong>거리</strong>가 얼마만큼 변경되었을 때 위치를 전달받을지 <strong>미터 단위</strong>로 설정한다.
      </li>
    </ul>
</ul>

```kotlin
// 1. 위치 한 번만 가져오기.
if (ContextCompat.checkSelfPermission(
    this, android.Manifest.permission.ACCESS_FINE_LOCATION
    ) === PackageManager.PERMISSION_GRANTED
)  {
  val location: Location? =
      // getLastKnownLocation()을 통해 사용자의 위치 정보를 얻는다.
      manager.getLastKnownLocation(LocationManager.GPS_PROVIDER)
  location?.let {
      val latitude = location.latitude
      val longitude = location.longitude
      val accuracy = location.accuracy
      val time = location.time

      Log.d("kkang", "$latitude, $longitude, $accuracy, $time")
  }
}
```

```kotlin
// 2. 위치 계속 가져오기.
//   - LocationListener 사용.
val listener: LocationListener = object : LocationListener {
    override fun onLocationChanged(location: Location) {
        Log.d("kkang", "${location.latitude}, ${location.longitude}, ${location.accuracy}")
    }

    override fun onProviderDisabled(provider: String) {
        super.onProviderDisabled(provider)
    }
 
    override fun onProviderEnabled(provider: String) {
        super.onProviderEnabled(provider)
    }
}
manager.requestLocationUpdates(LocationManager.GPS_PROVIDER, 
    
    // 위치 전달 주기 (10초)
    10_000L, 
    
    // 거리가 얼마나 떨어지면 위치를 전달받을지 (10m)
    10f, 
    listener)
(... 생략 ...)
manager.removeUpdates(listener)
```
