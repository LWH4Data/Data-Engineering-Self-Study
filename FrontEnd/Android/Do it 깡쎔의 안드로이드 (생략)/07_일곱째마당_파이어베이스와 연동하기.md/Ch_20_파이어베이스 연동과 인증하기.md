<h1>1. 파이어베이스 이해하기</h1>
<h2>1-1. 파이어베이스란?</h2>
<ul>
  <li>
    파이어베이스(Firebase)는 2011년 파이어베이스사가 개발하고 2014년 구글에 인수된 모바일과 웹 애플리케이션을 개발하는 플랫폼으로 <strong>서버리스 컴퓨팅</strong>을 구현할 수 있다.
  </li>
    <ul>
      <li>
        서버리스(serverless) 컴퓨팅이란 개발자가 서버를 별도로 구축하지 않고 데이터 센터나 클라우드에 필요한 기능을 <strong>함수 형태</strong>로 구현하여 전통적인 백엔드 대신 사용하는 방법을 의미한다.
      </li>
      <li>
        이때 모바일 앱은 프런트엔드로의 역할을 한다.
      </li>
    </ul>
  <li>
    파이어베이스의 경우 정식 서비스를 운영하려면 요금제에 가입이 필요하지만 테스트용은 무료 요금제로 개발이 가능하다.
  </li>
  <li>
    파이어베이스는 모바일 앱과 웹 애플리케이션을 개발하는 데 다음과 같은 여러 가지 핵심 기능을 제공한다.
  </li>
    <ul>
      <li>
        Authentication: 인증, 회원가입 및 로그인 처리
      </li>
      <li>
        Cloud Message: 알림 전송
      </li>
      <li>
        Firebase Database: 앱 데이터 저장 및 동기화
      </li>
      <li>
        Realtime Database: 실시간 데이터 저장 및 동기화
      </li>
      <li>
        Storage: 파일 저장소
      </li>
      <li>
        Hosting: 웹 호스팅
      </li>
      <li>
        Functions: 서버 관리 없이 모바일 백엔드 코드 실행
      </li>
      <li>
        Machine Learning: 모바일 개발자용 머신러닝
      </li>
    </ul>
</ul>

<ul>
  <li>
    파이어베이스의 인증(Authentication) 기능은 앱에서 <strong>회원가입</strong>이나 <strong>로그인</strong>을 처리할 때 사용한다.

<h2>3-1. 이메일/비밀번호 인증</h2>
<ul>
  <li>
    사용자의 회원가입 이메일/비밀번호를 파이어베이스에 저장하고 이를 활용해 로그인을 처리한다.
  </li>
    <ul>
      <li>
        이메일은 기존에 존재하는 이메일을 등록해야하며 비밀번호는 파이어베이스 연동 시스템에 로그인할 때 사용하는 비밀번호이다.
      </li>
    </ul>
</ul>

<h3>3-1-1. 이메일/비밀번호 인증 사용 설정하기</h3>
<ul>
  <li>
    도서의 실습을 따라한다.
  </li>
</ul>

<h3>3-1-2. 파이어베이스 인증 객체 얻기</h3>
<ul>
  <li>
    안드로이드 앱의 파이어베이스 인증 처리는 <strong>FirebaseAuth 객체를 얻는 것</strong>부터 시작한다.
  </li>
    <ul>
      <li>
        FirebaseAuth 객체는 각종 함수를 제공하며 회원가입, 로그인, 로그아웃, 구글 로그인 등을 처리할 수 있다.
      </li>
      <li>
        FirebaseAuth 객체는 Firebase.auth로 얻는다.
      </li>
    </ul>
</ul>

```kotlin
// 1. 파이어베이스 인증 객체 얻기.
lateinit var auth: FirebaseAuth
(... 생략 ...)
auth = Firebase.auth
```

<h3>3-1-3. 회원가입하기</h3>
<ul>
  <li>
    FirebaseAuth 객체의 <strong>createUserWithEmailAndPassword() 함수</strong>로 파이어베이스에 이메일/비밀번호를 등록한다.
  </li>
    <ul>
      <li>
        매개변수는 등록할 이메일과 비밀번호이다.
      </li>
      <li>
        결과는 addOnCompleteListener() 함수의 두 번째 매개변수로 등록하는 콜백 함수로 확인한다.
      </li>
    </ul>
  <li>
    콜백 함수의 매개변수 Task&ltAuthResult&gt 객체로 회원가입 성공/실패를 판단한다.
  </li>
    <ul>
      <li>
        Task 객체의 <strong>isSuccessful</strong>로 파이어베이스에 등록이 성공했는지 확인할 수 있다. 반대로 실패한 경우 <strong>exception</strong>으로 원인을 확인할 수 있다.
      </li>
    </ul>
  <li>
    마지막으로 이메일 인증을 해야하기에 이메일/비밀번호 등록이 성공했다면 FirebaseUser 클래스의 <strong>sendEmailVerification() 함수</strong>로 <strong>인증 메일</strong>을 보낸다.
  </li>
</ul>

```kotlin
// 1. 회원가입하기.
auth.createUserWithEamilAndPassword(email, password)
    .addOnCompleteListener(this) { task ->
    (... 생략 ...)
}
```

```kotlin
// 2. 회원가입 성공/실패 판단.
auth.createUserWithEmailAndPassword(email, password)
    .addOnCompleteListener(this) { task ->
        if (task.isSuccessful) {
            (... 생략 ...)
        } else {
            Log.w("kkang", "createUserWithEmail:failure", task.exception)
        }
    }
```

```kotlin
// 3. 인증 메일 발송하기(등록을 성공했을 때)
auth.createUserWithEmailAndPassword(email, password)
    .addOnCompeteListener(this) { task ->
        if (task.isSuccessful) {

            // auth.currentUser로 등록한 사용자 정보를 가져온다.
            //   - sendEmailVerification() 함수로 인증 메일을 전송한다.
            auth.currentUser?.sendEmailVerification()
                
                // 인증 메일 발송의 성공/실패는 addOnCompleteListener() 함수로 등록한 매개변수로 확인할 수 있다.
                //   - 매개변수에 지정한 함수가 자동으로 호출되어 성공/실패 여부를 알려준다.
                ?.addOnCompeteListener { sendTask ->
                    if (sendTask.isSuccessful) {
                        // ...
                    } else {
                        // ...
                    }
                }
        } else {
            Log.w("kkang", "createUserWithEmail:failure", task.exception)
        }
    }
```

<h3>3-1-4. 로그인하기</h3>
<ul>
  <li>
    가입한 사용자의 로그인을 처리할 때에는 <strong>signInWithEmailAndPassword() 함수</strong>를 이용한다.
  </li>
    <ul>
      <li>
        함수의 매개변수로 대입한 이메일과 비밀번호를 통해 파이어베이스와 연동한다.
      </li>
      <li>
        로그인 처리 결과는 addOnCompleteLIstener()에 등록된 함수를 호출해 알려준다.
      </li>
    </ul>
</ul>

```kotlin
// 1. 로그인 처리.
auth.signInWithEmailAndPassword(email, password)
    .addOnCompleteListener(this) { task ->
        if (task.isSuccessful) {
            // 로그인 성공했을 때 처리.
        } else {
            // 로그인 실패했을 때 처리.
        }
    }
```

<h2>3-2. 구글 인증</h2>
<ul>
  <li>
    파이어베이스는 다양한 업체의 인증 시스템과 연계가 가능하며 여기서는 구글 인증만 살펴본다.
  </li>
</ul>

<h3>3-2-1. 구글 인증 사용 설정하기</h3>
<ul>
  <li>
    교재 p628을 따라한다.
  </li>
    <ul>
      <li>
        implementation("com.google.android.gms:play-services-auth:21.2.0") 의존성을 추가한다.
      </li>
    </ul>
</ul>

<h3>3-2-2. 구글 인증 처리하기</h3>
<ul>
  <li>
    구글 인증은 안드로이드 시스템에 설치된 <strong>구글의 인증 앱</strong>과 연동하여 처리한다.
  </li>
    <ul>
      <li>
        앱에서 인텐트 정보를 설정하고 구글 인증 앱을 실행하면 구글 인증 앱이 처리 후 결과를 돌려준다.
      </li>
      <li>
        이후 사용자에게 구글 인증 정보를 입력받고 해당 정보로 구글 로그인을 시도하여 성공/실패 여부를 앱에 전달한다.
      </li>
    </ul>
</ul>

```kotlin
// 1. 구글 인증 앱 실행.
val gso = GoogleSignInOptions.Builder(GoogleSignInOptions.DEFAULT_SIGN_IN)
    .requesteIdToken(getString(R.string.default_web_client_id))
    .requestEmail()
    .build()

// 인텐트 객체 생성.
val signInIntent = GoogleSignIn.getClient(this, gso).signInIntent

// 인텐트 시작.
requestLauncher.launch(signInIntent)
```

```kotlin
// 2. 사용자가 입력한 정보를 통해 구글 인증 처리
val requestLauncher = registerForActivityResult(
    ActivityResultContracts.StartActivityForResult())

{
    val task = GoogleSignIn.getSignedInAccountFromIntent(it.data)
    try {
        val account = task.getResult(ApiException::class.java)!!
        val credential = GoogleAuthProvider.getCredential(account.idToken, null)
        MyApplication.auth.signInWithCredential(credential)
            .addOnCompleteLIstener(this) { task ->
                if (task.isSuccessful) {
                    // 구글 로그인 성공.
                } else {
                    // 구글 로그인 실패.
                }
            } catch (e: ApiException) {
                // 예외 처리.
            }
    }
}
```
