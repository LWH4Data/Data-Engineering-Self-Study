# 0. 개요

- **퍼셉트론(perceptron) 알고리즘**은 프랭크 로젠블랫(Frank Rosenblat)이 1957년 고안한 알고리즘이다.
- 퍼셉트론은 신경망(딥러닝)의 기원이 되는 알고리즘이다.

<br><br>

# 1. 퍼셉트론이란?

- 퍼셉트론은 **다수의 신호를 입력받아 하나의 신호**를 출력한다. 여기서 **신호**란 전류나 강물처럼 **흐름이 있는 무언가**로 받아들이면 된다.
  - 이번 장에서 소개하는 퍼셉트론은 정확히는 **단순 퍼셉트론** 혹은 **인공 뉴런**으로 불리는 것이다.
- 퍼셉트론은 실제 전류가 연속적인 것과 달리 신호가 흐르고 흐르지 않음을 **1과 0**으로 나타낼 수 있다.
- 예를 들어 두 개의 입력 $x_1$과 $x_2$가 있고, 하나의 출력 신호 $y$와 각 가중치(weight) $w_1$과 $w_2$가 있다.
  - $x_1$, $x_2$, $y$와 같은 각 원의 단위를 **뉴런** 혹은 **노드**라고 한다.
  - 입력 신호($x_1$, $x_2$)가 뉴런에 보내질 때에는 각각 고유한 가중치가 **곱해진다**. 현재는 $w_1x_1$과 $w_2x_2$가 된다.
    - 뉴런에서 보내온 신호의 총합이 정해진 한계를 넘어설 때만 1을 출력한다. 이를 뉴런이 활성화한다고 표현한다.
    - 책에서는 임곗값을 **$\theta$(세타, theta)** 기호로 나타낸다.

$$
y =
\begin{cases}
0 & \text w_1x_1 + w_2x_2 \le \theta \\
1 & \text w_1x_1 + w_2x_2 > \theta
\end{cases}
$$

- 퍼셉트로는 위와 같이 복수의 입력 신호에 각각 고유한 가중치를 부여하며 각 가중치는 **신호가 결과에 주는 영향력**을 조절하는 요소로 작용한다.
  - 예를 들어 가중치가 클수록 해당 신호가 그만큼 더 중요함을 의미한다.
  - 가중치는 전류에서 **저항**에 해당한다 볼 수 있다. 단, 정류는 가중치와 반대로 낮을 수록 전류가 강해진다.

# 2. 단순한 논리 회로
## 2-1. AND 게이트
- 논리 회로를 알아보는 첫 걸음으로 AND 게이트를 살펴본다.
- AND 게이트는 입력이 둘이고 출력이 하나이다.
  - 입력 신호와 출력 신호의 대응 표를 **진리표**라 한다.
  - AND 게이트는 두 입력이 모두 1일 때만 1을 출력하고, 그 외에는 0을 출력한다.
- AND 게이트로 퍼셉트론을 표현하고 싶다면 진리표 대로 작동하도록 $ w1 $, $ w2 $, $ \theta $를 결정하면 된다.
  - 즉 $ w_1x_1 + w_2x_2 > \theta $인 경우만 1이 되도록 하면 되며 예를 들어 (0.5, 0.5, 0.7) 등이 해당한다.

## 2-2. NAND 게이트와 OR 게이트
- NAND는 Not AND를 의미하며 **AND 게이트와 반대되는 값**을 출력한다.
  - 진리표로 나타내면 $ x_1 $과 $ x_2 $ 모두 1일 때에만 0을 출력하고 나머지는 모두 1을 출력한다.
  - 마찬가지로 이를 만족하는 수많은 조합이 있지만 AND 게이트를 구현하는 매개변수의 **부호를 모두 반전**하면 NAND 게이트가 된다.
- OR 게이트는 입력 신호 중 **하나 이상이 1**이면 출력이 1이 되는 논리 회로이다.
- 핵심은 AND, NAND, OR의 게이트가 모두 동일하며 차이는 **매개변수의 값**뿐이라는 것이다.
  - 즉 매개변수의 값만 적절히 조정하면 AND, NAND, OR로 유연하게 변경이 가능하다.

# 3. 퍼셉트론 구현하기
## 3-1. 간단한 구현부터

```python
# 1. x1과 x2를 인수로 받는 AND 함수.
def AND(x1, x2):
    # 각 매개변수 지정.
    w1, w2, theta = 0.5, 0.5, 0.7

    # 식 구현.
    tmp = x1*w1 + x2*w2

    # theta보다 작은 경우 0을 반환.
    if tmp <= theta:
        return 0
    
    # theta 보다 큰 경우에만 1을 반환.
    elif tmp > theta:
        return 1

AND(0, 0)
AND(1, 0)
AND(0, 1)
AND(1, 1)
```

## 3-2. 가중치와 편향 도입
- $ \theta $를 $ -b $로 치환하여, 즉 편향을 도입하여 식을 다음과 같이 표현할 수 있다.

$$
y =
\begin{cases}
0 & (b + w_1x_1 + w_2x_2 \le 0) \\
1 & (b + w_1x_1 + w_2x_2 > 0)
\end{cases}
$$

- $ b $는 편향(bias)를 의미하며 $ w_1 $과 $ w_2 $는 그대로 가중치(weight)이다.
  - 이렇게 표현하는 이유는 표기상의 편리 때문일 뿐 큰 의미는 없다.

```python
# 2. 넘파이를 활용해 바뀐 식 구현.
import numpy as np
x = np.array([0, 1])  # 입력
w = np.array([0.5, 0.5])  # 가중치
b = -0.7  # 편향

w*x
np.sum(w*x)
np.sum(w*x) + b  # 최종 식
```

## 3-3. 가중치와 편향 구현하기
- 편향($ b $)은 가중치($ w_1 $, $ w_2 $)와는 기능이 다르다.
  - 가중치는 각 입력 신호가 결과에 주는 **영향력(중요도)**을 조절하는 매개변수이다.
  - 편향은 뉴런이 **얼마나 쉽게 활성화(결과로 1을 출력)하느냐**를 조정하는 매개변수이다.
  - 도서에서는 가중치와 편향을 모두 가중치로 표현할 때에도 있다.
- 실습 코드는 DL_from_floor/ch02의 and_gate.py, nand_gate.py, or_gate.py 이다.

# 4. 퍼셉트론의 한계
## 4-1. 도전! XOR 게이트
- XOR 게이트는 **베타적 논리합**라는 논리 회로이다.
  - 즉 $ x_1 $과 $ x_2 $ 중 **한쪽이 1**일 때만 1을 출력한다. (배타적 = 자기 외에는 거부).
- 지금까지 살펴본 퍼셉트론으로는 XOR 게이트를 구현할 수 없다.
  - 정확히는 직선 하나로는 불가능하다.

## 4-2. 선형과 비선형
- 반면 비선형 관계를 활용하면 XOR 게이트와 같이 직선으로 구분이 안되는 게이트도 구현이 가능하다.
- 이때 비선형에 해당하는 영역을 **비선형 영역**, 직선에 해당하는 영역을 **선형 영역**이라 한다.

# 5. 다층 퍼셉트론이 출동한다면?
- 아쉽게도 단층 퍼셉트론(single-layer perceptron)만으로는 XOR 게이트를 표현할 수 없지만 퍼셉트론의 층을 쌓는 **다층 퍼셉트론(multo-layer perceptron)**으로는 표현이 가능하다.
  - 단층 퍼셉트론은 비선형 영역을 분리할 수 없다는 한계 또한 가진다.

## 5-1. 기존 게이트 조합하기
- XOR 게이트를 만드는 방법은 다양하며 그중 하나는 앞서 만든 **AND, NAND, OR 게이트를 조합**하는 방법이다.
  - $ x_1 $과 $ x_2 $를 각각 **NAND와 OR 게이트에 입력**하고 두 게이트의 결과를 **AND 게이트에 입력**으로 하는 방법이다. (p59의 그림 2-12 참고).

## 5-2. XOR 게이트 구현하기
- 지금까지 정의한 함수로 구현이 가능하며 코드는 DL_from_floor/ch02/xor_gate.py 이다.
- 그림으로 나타내면 $ x_1 $와 $ x_2 $기 첫 번째 계층에, 그리고 NAND와 OR 게이트를 통과한 결과가 $ s_1 $와 $ s_2 $로 두 번째 계층에, 그리고 가장 마지막에 AND 게이트를 통과한 결가 $ y $가 되는 다층 퍼셉트론이 된다. (p60 그림 2-13 참고).
  - 즉 XOR는 2층 퍼셉트론이다.
  - 0층의 뉴런이 입력 신호를 받아 1층의 뉴런으로 신호를 보내면 1층의 뉴런이 2층의 뉴런으로 신호를 보내고 2층의 뉴런은 y를 출력한다.
- 핵심은 단층 퍼셉트론으로 표현하지 못하던 것을 **층을 늘려 구현**할 수 있었다는 것이며 이처럼 퍼셈트론은 **층을 쌓아 더 다양한 대상**을 표현할 수 있다.

# 6. NAND에서 컴퓨터까지
- 다층 퍼셉트론은 지금까지 보아온 회로보다 복잡한 회로를 만들 수 있다.
  - 심지어 컴퓨터도 정보 처리 기계이기 때문에 NAND 게이트만으로 컴퓨터를 만들 수 있다.
  - 실제로 '밑바닥부터 만드는 컴퓨팅 시스템' 도서에서는 NAND만으로 테트리스가 작동하는 컴퓨터를 만든다.
    - 쉬운 것은 아니며 실제로는 NAND 등의 저수준 소자에서 시작하여 컴퓨터를 만드는 데 필요한 부품(모듈)을 단계적으로 만들어가는 쪽이 자연스럽다.
    - 예를 들어 AND와 OR 게이트 → 반가산기와 전가산기 → 산순 논리 연산 장치(ALU) → CPU와 같다.
