# 0. 개요
- 합성곱 신경망(Convolutional Neural Network, CNN)은 이미지 인식과 음성 인식 등 다양한 곳에서 사용되는데, 특히 이미지 인식 분야에서 많이 활용된다.

<br><br>

# 1. 전체 구조
- CNN도 지금까지 본 신경망과 동일하게 레고 블록처럼 계층을 조합하여 만들며 이때 <strong>합성곱 계층(Convolutional layer)</strong>과 <strong>풀링 계층(pooling layer)</strong>을 활용한다.
- 지금까지 본 신경망은 인접하는 계층의 모든 뉴런과 결합되어 있으며 이를 <strong>완전연결(fully-connected, 전결합)</strong>이라 한다.
  - 완전히 연결된 계층을 <strong>Affine 계층</strong>이라는 이름으로 구현하였다.
- CNN의 계층은 <strong>'Conv-ReLU-(Pooling)'</strong> 흐름으로 연결된다.
  - 마지막 출력 계층에서는 Affine-Softmax 조합을 그대로 활용한다.

<br><br>

# 2. 합성곱 계층
- CNN에서는 패딩(padding), 스트라이드(stride)와 같이 CNN의 고유 용어가 등장한다.
- 각 계층 사이에는 3차원 데이터와 같이 입체적인 데이터가 흐른다.

## 2-1. 완전연결 계층의 문제점
- 완전연결 계층의 문제점은 <strong>이터의 형상이 무시</strong>된다는 것이다.
  - 예를 들어 이미지의 경우 세로, 가로, 색상으로 구성된 3차원 데이터이지만 완전연결 계층에 입력할 때에는 1차원 데이터로 평탄화 된다.
  - 공간적 거리나 RGB, 그리고 3차원 속에서 의미를 갖는 본질적인 패턴을 놓칠 수 있다.
- 합성곱 계층은 형상을 유지하기 때문에 위의 완전연결 계층의 단점을 해결한다.
  - CNN에서 합성곱 계층의 입출력 데이터를 <strong>특징 맵(feature map)</strong>이라고도 한다.
  - 입력 데이터는 <strong>입력 특징 맵(input feature map)</strong>, 출력 데이터는 <strong>출력 특징 맵(output feature map)</strong>이라고 한다.
- 도서에서는 입출력 데이터와 특징 맵을 같은 의미로 사용한다.

## 2-2. 합성곱 연산
- 합성곱 계층에서는 <strong>합성곱 연산</strong>을 처리한다. 합성곱 연산이란 이미지 처리에서 말하는 <strong>필터연산</strong>에 해당한다.
- 연산에 적용되는 필터를 <strong>커널</strong>이라 칭하기도 한다. (p231의 합성곱 연산 과정 참고).
- 합성곱 연산은 필터의 <strong>윈도우(window)</strong>를 일정 간격으로 이동해가며 입력 데이터에 적용한다.
  - 입력과 필터에서 대응하는 원소끼리 곱한 후 그 총합을 구한다. 이 계산을 <strong>단일 곱셈-누산(fused multiply-add, FMA)</strong>이라 한다.
  - 각 연산의 결과는 해당 장소에 저장하며 연산을 <strong>모든 장소</strong>에서 수행하면 합성곱 연산의 출력이 완성된다.
- CNN에서는 <strong>필터의 매개변수</strong>가 완전연결 신경망에서의 가중치에 해당핞다.
- <strong>편향</strong>은 필터를 적용한 후의 데이터에 더해지며 <strong>항상 하나($1\times1$)</strong>만 존재한다.
  - 하나의 값을 모든 원소에 더하는 것이다.

## 2-3. 패딩
- 합성곱 연산을 수행하기 전에 입력 데이터 주변을 <strong>특정 값(예컨대 0)</strong>으로 채우기도하며 이를 <strong>패딩(padding)</strong>이라 한다.
  - 폭이 1인 패딩이라면 입력 데이터에 폭이 1인 패딩을 적용한 모습이다.
- 패딩은 주로 <strong>출력 크기를 조정</strong>할 목적으로 사용한다.
  - 예를 들어 (4, 4) 입력 데이터에 (3, 3) 필터를 적용하면 출력은 (2, 2)가 되어 입력보다 줄어들기 때문에 이런 상황을 방지한다.
  - 즉 입력 데이터의 공간적 크기를 고정한 채로 다음 계층에 전달할 수 있다.

## 2-4. 스트라이드
- 필터를 적용하는 위치의 간격을 <strong>스트라이드(stride)</strong>라고 한다.
- 스트라이드를 크게하면 출력의 크기가 작아진다. 반면 패딩을 크게하면 출력의 크기가 커진다. 이를 수식으로 나타내면 다음과 같다.
  - $(H,\space W)$: 입력 크기.
  - $(FH,\space FW)$: 필터 크기.
  - $(OH,\space OW)$: 출력 크기.
  - $P$: 패딩
  - $S$: 스트라이드
- 단, 각 출력의 값($OH, \space OW)$는 정수로 나눠떨어지는 값이어야 한다.
  - 딥러닝 프레임워크 중에는 값이 딱 나눠떨어지지 않을 때 가장 가까운 정수로 반올림하는 등의 경우도 있다.

$$
\begin{align}
&OH=\frac{H+2P-FH}{S}-1 
\\[1.5em]
&OW=\frac{W+2P-FW}{S}+1
\end{align}
$$

## 2-5. 3차원 데이터의 합성곱 연산
- 이전 과정에 더하여 <strong>채널</strong>까지 고려한 3차원 데이터를 다루는 합성곱 연산을 다룬다.
- 3차원 데이터의 합성곱 연산의 경우 채널 크기에 맞춰 특징 맵이 늘어난다. 
  - 이후 연산 과정은 2차원 데이터의 합성곱과 동일하게 진행된다. (p236 참고).
- 3차원 합성곱에서 주의할 점은 <strong>입력 데이터의 채널 수와 필터의 채널 수가 같아야한다는 것</strong>이다.
  - 필터 자체의 크기는 <strong>원하는 값</strong>으로 설정할 수 있다.

## 2-6. 블록으로 생각하기
- 3차원 합성곱 연산은 데이터와 필터를 <strong>직육면체 블록</strong>이라고 생각하면 쉽게 이해할 수 있다.
  - 3차원 데이터를 다차원 배열로 나타낼 때는 채널(channel), 높이(height), 너비(width) 순으로 쓸 수 있다.
- 필터를 FN개 적용하면 출력 맵도 FN개가 생성된다.
- 합성곱 연산에서는 필터의 수도 고려해야하며 따라서 필터의 가중치 데이터는 4차원 데이터로 출력 채널 수, 입력 채널 수, 높이, 너비 순으로 쓴다.
- 마찬가지로 합성곱 연산에도 <strong>편향</strong>을 사용한다.
  - 편향은 채널 하나에 값 하나씩으로 구성되기 때문에 편향의 형상은 (FN, 1, 1)이다.
  - 편향을 출력 결과에 더하면 되며 이는 브로드캐스트 기능으로 쉽게 구현할 수 있다.

## 2-7. 배치 처리
- 합성곱 신경망도 배치 처리를 지원하며 이를 위해 데이터의 차원을 하나 늘려 <strong>4차원 데이터</strong>로 저장한다.
  - 구체적으로는 (데이터 수, 채널 수, 높이, 너비) 순으로 저장한다.

# 3. 풀링 계층
- 풀링은 세로와 가로 방향의 공간을 <strong>줄이는 연산</strong>이다.
- 최대 풀링(max pooling)은 <strong>주어진 대상 영역에서 가장 큰 원소</strong> 하나를 꺼내어 적용하는 것이다.
- 풀링의 윈도우 크기와 스트라이드는 같은 값으로 설정하는 것이 보통이다.
- 풀링에는 최대 풀링 외에도 평균 풀링(average pooling) 등이 있는데 이미지에서는 주로 최대 풀링을 사용한다.

## 3-1. 풀링 계층의 특징
- 학습해야 할 매개변수가 없다.
  - 풀링 계층은 합성곱 계층과 달리 학습해야할 매개변수가 없다.
- 채널 수가 변하지 않는다.
  - 풀링 연산은 입력 데이터의 채널 수 그대로 출력 데이터로 내보낸다.
- 입력의 변화에 영향을 적게 받는다(강건하다).
  - 입려 데이터의 차이를 풀링이 흡수하기 때문이다.

## 4-2. im2col로 데이터 전개하기
- im2col은 image to column으로 <strong>이미지에서 행렬</strong>로 변환한다는 의미이다.
- 합성곱을 곧이곧대로 구현하려면 for 문을 겹겹이 써야하고, 또 numpy는 원소에 접근할 때 for 문을 사용하지 않는 것이 바람직하다는 문제가 있다. 이때 for 대신 <strong>im2col</strong>을 사용하면 간단히 구현할 수 있다.
- im2col은 입력 데이터를 필터링(가중치 계산)하기 좋게 <strong>전개</strong>하는 함수이다.
  - 3차원 입력 데이터에 im2col을 적용하면 ㅈ차원 행렬로 바뀐다 (p243).
  - 정확히는 입력 데이터에서 필터를 적용하는 영역(3차원 블록)을 <strong>한 줄</strong>로 늘어놓는다.
  - 스트라이드가 충분히 크지 않으면 실제 상황에서는 영역이 겹치는 경우가 대부분이다.
    - 이유는 im2col은 데이터를 1:1로 변환하는 게 아니라 필터가 적용되는 위치 수(N)만큼 각 영역을 평탄화하여 1:N으로 변환하기 때문이다.
- im2col는 데이터의 <strong>필터 적용 영역</strong>을 앞에서부터 순서대로 <strong>row</strong>로 펼친다. 마찬가지로 각 <strong>필터</strong>를 <strong>column으로 전개</strong>하고 행렬 곱을 계산하면 한 번에 연산을 수행할 수 있다.
  - 이후 출력 데이터를 변형(reshape)하면 연산이 끝난다.
  - CNN은 데이터를 4차원 배열로 저장하기 때문에 2차원인 출력 데이터를 4차원으로 변형(reshape)한다.

## 4-4. 풀링 계층 구현하기
- 풀링 계층도 합성곱 계층과 동일하게 im2col을 사용해 입력 데이터를 전개한다.
  - 단 풀링의 경우에는 <strong>채널 쪽이 독립적</strong>이라는 점이 합성곱 계층 때와 다르다. 
  - 풀링은 전체 값을 그대로 유지하는 것이 아니라, 각 채널의 일정한 공간 영역에서 최댓값이나 평균값 같은 <strong>대표값을 추출</strong>하여 <strong>특징 맵의 공간적 크기를 줄이는 것</strong>이 목적이기 때문이다.
- 풀링 계층을 구현한 코드는 DL_from_floor/common/layers.py에 있다. 계층 구현은 다음과 같은 세 단계로 진행된다.
  - 입력 데이터를 전개한다.
  - 행별 최댓값을 구한다.
  - 적절한 모양으로 성형한다.

# 6. CNN 시각화하기
## 6-1. 1번째 층의 가중치 시각화하기
- 1번째 층의 합성곱 계층의 가중치 형상은 (30, 1, 5, 5)이다 (필터, 채널, 크기).
  - 다시 말하면 $5 \times 5$ 1채널 회색조 이미지로 시각화할 수 있으며 해당 코드는 DL_from_floor/ch07/visualize_filter.py에 있다.
- 학습 전의 필터는 무작위로 초기화되어 흑백의 정도에 규칙성이 없으나 학습 후엔는 규칙성이 있는 모습을 확인할 수 있다. 즉 규칙을 띄는 필터로 변경된다.
  - 필터가 학습하는 규칙은 지금 예에서는 에지(색상이 바뀐 경계선)와 블롭(국소적으로 덩어리진 영역) 이다.
- CNN에서 필터는 이런 국소적인 정보를 추출하여 뒷단을 계층으로 전달한다.

## 6-2. 층 깊이에 따른 추출 정보 변화\
-
