# 0. 개요
- 퍼셉트론은 복잡한 함수를 표현할 수 있지만 가중치를 설정하는 작업은 사람이 수동으로 해야한다는 단점이 있다.
- 그러나 **신경망**은 가중치 매개변수의 적절한 값을 **데이터로부터 자동으로 학습**하여 사람이 **가중치를 설정**하는 작업을 대신해준다.

<br><br>

# 1. 퍼셉트론에서 신경망으로
## 1-1. 신경망의 예
- 신경망에는 입력층, 출력층, 은닉층이 있다. (p64의 그림 3-1).
  - 은닉층의 뉴런은 입력층이나 출력층과 달리 사람 눈에는 보이지 않기 때문에 은닉이라 부른다.
  - 도서에서는 입력층에서 출력층 방향으로 0층, 1층, 2층으로 부른다. (python 구현의 편리함 때문).
- 주의! 문헌에 따라서 신경망의 층 수를 그대로 표기하기도하지만 **실제 가중치를 갖는 층의 개수(입력층 + 은닉층 + 출력층 - 1)**로 표기하는 경우도 있다.

## 1-2. 퍼셉트론 복습

$$
y =
\begin{cases}
0 & (b + w_1x_1 + w_2x_2 \le 0) \\
1 & (b + w_1x_1 + w_2x_2 > 0)
\end{cases}
$$

- 퍼셉트론의 수식은 위와 같다.
  - $ b $는 편향을 나타내는 매개변수로 뉴런이 얼마나 쉽게 활성화되느냐를 제어한다.
  - $ w_1 $과 $ w_2 $는 각 신호의 가중치로 각 신호의 영향력을 제어한다.
  - 편향을 포함하여 퍼셉트론을 시각화할 수 있다.
    - 단 편향의 입력 신호는 항상 1이다.
- 퍼셉트론 식을 $ h(x) $로하여 더 아래와 같이 더 간단히 표현할 수 있다.
  - 입력 신호의 총 합이 $ h(x) $라는 함수를 거쳐 변환되고 변환된 값이 $ y $의 출력이 된다.

$$
y = h(b + w_1x_1 + w_2x_2)
$$

$$
h(x) = 
\begin{cases}
0 & (x \le 0) \\
1 & (x > 0)
\end{cases}
$$

## 1-3. 활성화 함수의 등장
- 앞서 $ h(x) $라는 함수가 등장했는데 이처럼 입력 신호의 총합을 출력 신호로 변환하는 함수를 **활성화 함수(activation function)**이라 한다.
  - 활성화 함수는 이름 그대로 입력 신호의 총합이 **활성화를 일으키는지**를 정하는 역할을 한다.
- 퍼셉트론의 식을 활성화 함수로 표현하면 다음과 같이 나타낼 수 있다.
  - 첫 번째 식은 가중치가 달린 입력 신호의 편향과 총합을 계산하고 이를 $ a $라 한다.
  - 두 번째 식은 $ a $를 함수 $ h() $에 넣어 $ y $를 출력한다.

$$
a = b + w_1x_2 + w_2x_2
$$

$$
y = h(a)
$$

- 뉴런은 보통 **하나의 원**으로 표현한다. 신경망의 동작을 더 명확히 드러내고자 할 때는 큰 원 안에 원을 추가하여 **활성화 처리 과정을 명시**하기도 한다.
- 도서에서는 단순 퍼셉트론과 다층 퍼셉트론을 엄밀히 구분하지는 않는다.
  - **단순 퍼셉트론**은 단층 네트워크에서 **계단 함수(임곗값을 경계로 출력이 바뀌는 함수)**를 활성화 함수로 사용한다.
  - **다층 퍼셉트론**은 **신경망(여러 층으로 구성되고 시그모이드 함수 등의 매끈한 활성화 함수를 사용하는 네트워크)**을 가리킨다.

<br><br>

# 2. 활성화 함수
- 활성화 함수는 임곗값을 경계로 출력이 바뀌는데, 이런 함수를 **계단 함수(step function)**이라 한다.
  - 앞서 살펴본 퍼셉트론은 계단 함수를 활성화 함수로 사용한다.
- 활성화 함수를 계단 함수에서 다른 함수로 변경할 수 있는데 이 점이 **신경망으로 나아가는 열쇠**이다.

## 2-1. 시그모이드 함수
- 신경망에서 자주 사용되는 활성화 함수인 시그모이드 함수(sigmoid function)의 식은 다음과 같다.
  - $ exp(-x) $는 $ e^{-x} $를 의미한다.
    - $ e $는 자연상수로 2.7182...의 값을 갖는 실수이다.
  - 복잡해 보일 수 있으나 결국 입력과 출력으로 된 함수이다.
- 신경망에서는 활성화 함수로 시그모이드 함수를 이용해 신호를 변환하고, 변환된 신호를 다음 뉴런에 전달한다.

$$
h(x) = {1 \over {1+\exp(-x)}} 
$$

## 2-2. 계단 함수 구현하기

```python
# 1. 계단 함수 단순 구현.
#   - 인수로 실수만 받아들인다는 단점이 있음.
def step_function(x):
    if x > 0:
        return 1
    else:
        return 0
```

```python
# 2. 넘파이 배열도 지원하도록 계단 함수 구현.
def step_function(x):
    
    # 넘파이 배열에 부등호 연산을 수행하면 배열의 
    # 원소 각각에 부등호 연산을 수행한 bool 배열 생성.
    y = x > 0

    # bool 배열의 원소를 int형으로 바꾸어 
    # 0과 1로 출력 되도록 함.
    return y.astype(int)
```

## 2-4. 시그모이드 함수 구현하기

  - 넘파이 배열을 넣어도 브로드캐스트 연산을 통해 정상적으로 연산이 수행된다.

## 2-5. 시그모이드 함수와 계단 함수 비교
- 시그모이드 함수는 **부드러운 곡선**이며 입력에 따라 출력이 **연속적으로 변화**한다.
  - 계단 함수는 0을 기점으로 출력이 갑자기 바뀐다.
- 계단 함수를 사용하는 퍼셉트론에서는 결과가 0과 1중 하나였지만 시그모이드 함수를 사용하는 신경망에서는 **연속적인 실수**가 결과로 반환된다.
- 시그모이드 함수와 계단 함수의 공통점은 다음과 같다.
  - 입력이 커지면 1에 가까워진다. 즉 입력이 **중요하면 큰 값**을 출력하고 **중요하지 않으면 작은 값**을 출력한다.
  - 입력이 아무리 작거나 커도 **출력은 0에서 1 사이**이다.

## 2-6. 비선형 함수
- 계단 함수와 시그모이드 함수의 중요한 공통점 중 하나는 **비선형 함수**라는 것이다.
- 함수란 어떤 값을 입력하면 그에 따른 값을 돌려주는 변환기이다.
  - 출력이 **입력의 상수배**만큼 변하는 함수를 **선형 함수**라 한다.
  - **비선형 함수**는 문자 그대로 **선형이 아닌 함수**를 의미한다.
- 신경망에서는 활성화 함수로 비선형 함수를 사용해야 한다.
  - 아무리 층이 깊어도 은닉층이 없는 네트워크는 똑같은 기능을 할 수 있기 때문이다.

## 2-7 ReLU 함수
- 시그모이드는 신경망 분야에서 오래전부터 이용했으나, 최근에는 **ReLU(Rectified Linear Unit)** 함수를 주로 이용한다.
- ReLU는 0을 넘으면 **입력을 그대로 출력**하고, 0 이하면 **0을 출력**하는 함수이다.

$$
h(x)=
\begin{cases}
x & (x > 0) \\
0 & (x \le 0)
\end{cases}
$$

- RuLU의 구현은 DL_from_floor/ch03/relu.py에 있다.

## 3-2. 행렬의 곱
- 행렬 곱은 **왼쪽 행렬의 행(가로)**와 **오른쪽 행렬의 열(세로)**을 원소별로 곱하고 그 값들을 더하여 계산한다.
  - 계산 결과는 새로운 다차원 배열의 원소가 된다.
- np.dot()은 입력이 1차원 배열이면 벡터를, 2차원 배열이면 행렬 곱을 계산한다.
  - 주의할 점은 행렬의 경우 인자의 **순서**에 따라 결과가 달라질 수 있다.
  - 또한 일반적으로 행렬의 곱에서 **앞 행렬의 열 수와 뒷 행렬의 행 수가 일치**해야하는 조건 또한 만족해야 한다.

```python
# 1. 행렬 곱.
A = np.array([[1, 2], [3, 4]])
A.shape

B = np.array([[5, 6], [7, 8]])
B.shape

np.dot(A, B)
```

```python

B.shape

np.dot(A, B)
```


# 4. 3층 신경망 구현하기
- 입력층(0층)은 2개, 첫 번째 은닉층(1층)은 3개, 두 번째 은닉층(2층)은 2개, 출력층(3층)은 2개의 뉴런으로 구성된다.

## 4-1. 표기법 설명
- 중요한 점은 신경망의 각 층의 계산은 **행렬의 곱**으로 처리할 수 있다는 것이다.
- $ w^{(1)}_{1 \space 2} $
  - (1): 1층의 가중치를 의미한다.
  - 1과 2는 앞 층의 두 번째 뉴런($ x_2 $)에서 다음 층의 첫 번째 뉴런($ a^{(1)}_{1} $)으로 향할 때의 가중치를 의미한다.
    - 즉 **다음 층 번호, 앞 층 번호**를 의미한다.

## 4-2. 각 층의 신호 전달 구현하기
- 만약 앞 층의 뉴런이 하나라면 출발점의 뉴런 표기를 생략할 수 있다.
- 따라서 1층의 1번째 뉴런으로 가는 식은 다음과 같다.

$$
a^{(1)}_1 = w^{(1)}_{1 \space 1}x_1 + w^{(1)}_{1 \space 2}x_2 + b^{(1)}_1
$$

- 행렬 곱을 이용하면 다음과 같이 가중치 부분을 간소화 할 수 있다.

$$
\mathbf{A^{(1)}} = \mathbf{X}\mathbf{W}^{(1)} + \mathbf{B}^{(1)}
$$

$$
{\scriptstyle
\mathbf{A^{(1)}}=
\begin{pmatrix}
a^{(1)}_1 & a^{(1)}_2 & a^{(1)}_3
\end{pmatrix}
,
\space
\mathbf{X}=
\begin{pmatrix}
x_1, x_2
\end{pmatrix}
,
\space
\mathbf{B}^{(1)}=
\begin{pmatrix}
b^{(1)}_1 & b^{(1)}_2 & b^{(1)}_3
\end{pmatrix}
}

\\

{\scriptstyle
W^{(1)}=
\begin{pmatrix}
w^{(1)}_{11} & a^{(1)}_{21} & a^{(1)}_{31} \\
a^{(1)}_{12} & a^{(1)}_{22} & a^{(1)}_{32}
\end{pmatrix}
}
$$

```python
# 1. 다차원 배열로 입력층 -> 1층 신경망을 연산.
X = np.array([1.0, 0.5])
W1 = np.array([[0.1, 0.3, 0.5], [0.2, 0.4, 0.6]])
B1 = np.array([0.1, 0.2, 0.3])

print(W1.shape)
print(X.shape)
print(B1.shape)

A1 = np.dot(X, W1) + B1
```

```python
# 2. 시그모이드 함수 적용.
Z1 = sigmoid(A1)

print(A1)
print(Z1)
```

```python
# 3. 1층 -> 2층 신경만 연산 구현.
#   - 1층의 출력 Z1이 2층의 입력이 되는 것 외에는 과정이 동일하다.
W2 = np.array([[0.1, 0.4], [0.2, 0.5], [0.3, 0.6]])
B2 = np.array([0.1, 0.2])

print(W2.shape)
```

## 4-3. 구현 정리
- 앞서 구현한 코드를 하나의 코드로 정리한다.
- 신경망 구현 관례에따라 가중치만 W1과 같이 대문자로 작성하고 그 외 편향과 중간 결과는 모두 소문자로 작성한다.

```python
# 가중치와 편향을 초기화하고 이들을 딕셔너리 변수인 network에 저장한다.
def init_network():
    network = {}
    network['W1'] = np.array([[0.1, 0.3, 0.5], [0.2, 0.4, 0.6]])
    network['b1'] = np.array([0.1, 0.2, 0.3])
    network['W2'] = np.array([[0.1, 0.4], [0.2, 0.5], [0.3, 0.6]])
    network['b2'] = np.array([0.1, 0.2])
    network['W3'] = np.array([[0.1, 0.3], [0.2, 0.4]])
    network['b3'] = np.array([0.1, 0.2])

    return network

# 입력 신호를 출력으로 변환하는 처리 과정을 모두 구현한다.
#   - 함수명 forward는 신호가 순방향으로 전달됨을 의미한다.
def forward(network, x):
    W1, W2, W3 = network['W1'], network['W2'], network['W3']
    b1, b2, b3 = network['b1'], network['b2'], network['b3']

    a1 = np.dot(x, W1) + b1
    z1 = sigmoid(a1)
    a2 = np.dot(z1, W2) + b2
    z2 = sigmoid(a2)
    a3 = np.dot(z2, W3) + b3
    y = identity_function(a3)

    return y

network = init_network()
x = np.array([1.0, 0.5])
y = forward(network, x)
print(y)
```

# 5. 출력층 설계하기
- 신경망은 분류와 회귀에 모두 이용할 수 있다.
  - 회귀의 경우 **항등 함수**를 출력층으로 한다.
  - 분류의 경우 **소프트맥스 함수**를 사용한다.

## 5-1. 항등 함수와 소프트맥스 함수 구현하기
- 항등 함수(identity function)는 **입력을 그대로 출력**한다.
- 항등 함수에 의한 변환은 은닉층에서 활성화 함수와 마찬가지로 화살표로 그린다.
- 분류에서 사용하는 소프트맥스 함수(softmax function)의 식은 다음과 같다.
  - $ \exp(x) $는 $ e^x $를 뜻하는 지수 함수(exponential function)이다.
  - $ n $은 출력층의 뉴런 수, $ y_k $는 그중 $ k $번째 출력층을 의미한다.
  - 분자는 입력 신호 $ a_k $의 지수 함수, 분모는 모든 입력 신호의 지수 함수의 합으로 구성된다.

$$
y_k = {\exp(a_k) \over {\sum^n_{i=1}\exp(a_i)}}
$$

```python
# 1. 소프트맥수 함수 연산.
a = np.array([0.3, 2.9, 4.0])

exp_a = np.exp(a)  # 지수 함수.
print(exp_a)

sum_exp_a = np.sum(exp_a)  # 지수 함수의 합
print(sum_exp_a)

y = exp_a / sum_exp_a
print(y)
```

```python
# 2. 소프트맥스 함수를 함수로 구현.
def softmax(a):
    exp_a = np.exp(a)
    sum_exp_a = np.sum(exp_a)
    y = exp_a / sum_exp_a

    return y
```

## 5-2. 소프트맥스 함수 구현 시 주의점
- 소프트맥스 함수를 컴퓨터로 계산할 때에는 **오버플로 문제**가 발생할 수 있다.
  - 지수 함수의 경우 **큰 값**을 반환하며 이는 나눗셈을 할 경우 수치가 불안정해지는 문제 또한 내포한다.
  - 컴퓨터는 수(number)를 4바이트나 8바이트와 같이 크기가 유한한 데이터로 다루기 때문에 너무 큰 수는 표현이 불가하며 이 현상이 오버플로이다.
- 위와 같은 문제로 인해 소프트맥스 함수 구현을 아래와 같이 개선한다.
  - 핵심적인 내용은 임의의 수 $ C $를 더하여 오버플로를 막는 것이다.
    1. C라는 임의의 정수를 분자와 분모 양쪽에 곱한다.
    2. C를 지수 함수 내부로 옮겨 $ \log C $로 만든다.
    3. $ log C $를 새로운 기호 $ C' $로 바꾼다.

$$
y_k = {\exp(a_k) \over {{\sum^n_{i=1}\exp(a_i)}}} = {C\exp(a_k) \over C\sum^n_{i=1}\exp(a_i)} \\[1em]
= {\exp(a_k+\log C) \over \sum^n_{i=1}\exp(a_i+\log C)} \\[1em]
= {\exp(a_k+C') \over \sum^n_{i=1}\exp(a_i+C')}
$$

```python
# 1. 개선된 소프트맥스 함수 연산.
a = np.array([1010, 1000, 990])
np.exp(a) / np.sum(np.exp(a))  # 소프트맥스 함수의 계산(오버플로)

c = np.max(a)  # c = 1010
a - c

np.exp(a - c) / np.sum(np.exp(a - c))
```

```python
# 2. 개선된 소프트맥스 함수 함수로 구현.
def softmax(a):
    c = np.max(a)
    exp_a = np.exp(a - c)  # 오버플로 개선.
    sum_exp_a = np.sum(exp_a)
    y = exp_a / sum_exp_a

    return y
```

## 5-3. 소프트맥스 함수의 특징
- 소프트맥스 함수는 각 **출력이 0 ~ 1 사이**이고, **총합이 1**이 되는 특징으로 인해 **확률로 해석**이 가능하다.
- 다만 소프트맥스 함수를 사용해도 각 원소의 **대소 관계**는 변하지 않는다.
  - 따라서 지수로 변환하는 비용을 아끼고 softmax 레이어를 제거한 뒤 가장 큰 값으로 분류하는 방법을 많이 사용한다.
- 다만 softmax 레이어를 생략하는 것은 **추론 단계**에만 해당한다.
  - 학습 단계에서는 softmax 레이어를 제거할 경우 모델이 **얼마나 틀렸는지 분간하기 힘든 경우**가 있으며 학습에 부정적이다.

```python
# 1. softmax() 함수를 사용하여 신경망 출력 계산.
a = np.array([0.3, 2.9, 4.0])
y = softmax(a)

# 출력은 0 ~ 1 사이이다.
print(y)

# 총합은 1이 된다.
np.sum(y)
```

## 5-4. 출력층의 뉴런 수 정하기
- 출력층의 뉴런 수는 풀려는 문제에 맞게 적절히 정해야하며 분류의 경우 **분류하고 싶은 클래스의 수**로 설정하는 것이 일반적이다.

## 6-1. MNIST 데이터 셋
- 이미지 인식이나 머신러닝 논문들에 자주 사용되는 실험용 데이터셋이다.
- MNIST 데이터셋은 0부터 9까지의 숫자로 이미지가 구성되며 훈련 이미지 60,000장과 시험 이미지 10,000장이 준비되어 있다.
- MNIST의 이미지 데이터는 28 x 28 크기의 회색조 이미지(1채널)이며, 각 픽셀은 0에서 255까지의 값을 취한다.
- 파이썬에는 **pickle**이라는 기능이 있는데 **프로그램 실행 중**에 특정 객체를 **파일로 저장**하는 기능이다.
  - 덕분에 load_mnist() 함수에서도 데이터를 빠르게 준비할 수 있다.

```python
# 1. MNIST 데이터 가져오기.
```

## 6-2. 신경망의 추론 처리
- MNIST 데이터셋을 위한 추론 신경망을 구축하는데 입력층 뉴런 784개, 출력층 뉴런을 10개로 구성한다.
  - 입력층 뉴런이 784개인 이유는 이미지의 크기가 28 x 28 = 784이기 때문이다.
  - 출력층이 10개인 이유는 문제가 0에서 9까지의 숫자를 구분하는 문제이기 때문이다.
  - 은닉층은 총 두개로 첫 번째 은닉층에는 50개의 뉴런을, 두 번째 은닉층에는 100개의 뉴런을 배치한다. (임의값)
- 실습 코드는 DL_from_floor/ch03/neuralnet_mnist.py에 있다.
- 코드에서 데이터를 불러오는 load_mnist 함수를 처리할 때 normalize를 True로 설정하였다.
  - normalize는 **정규화(normalization)** 옵션으로 데이터를 **특정 범위로 변환**한다.
  - 정규화와 같이 입력 데이터에 특정 변환을 가하는 작업을 **전처리(pre-processing)**이라 한다.
- 현업에서는 보통 데이터 전테의 분포를 고려해 전처리를 하는 경우가 많다.
  - 표준화를 하거나 전체 데이터를 균일하게 분포시키는 데이터 백색화(whitening) 등도 있다.

## 6-3. 배치 처리
- 하나의 이미지 데이터만을 입력할 때에는 (784, ) 차원이다.
  - 만약 100개의 이미지 데이터를 입력한다면 (784, 100)이 되며 출력($ y $) 또한 (100, 10)이 된다.
- 위와 같이 입력 데이터를 하나로 묶은 것을 **배치(batch)**라 한다.
  - 배치 처리는 데이터 전송이 병목으로 작용하는 것을 완화한다. 즉 버스에 주는 부하를 줄여준다.
    - 다만 대역폭이 작은 경우에는 버스의 부하를 줄여도 큰 의미가 없을 수 있다.
- 배치 처리를 구현한 코드는 DL_from_floor/ch03/neuralnet_mnist_batch.py에 있다.
