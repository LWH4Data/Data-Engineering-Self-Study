# 0. 개요
- 학습이란 **훈련 데이터**로부터 **가중치 매개변수의 최적값**을 자동으로 획득하는 것을 의미한다.
- 이번 장에서는 신경망이 학습할 수 있도록 해주는 지표인 **손실 함수**를 학습힌다.
  - 이를 위한 기법으로 경사 하강법을 소개한다.

<br><br>

# 1. 데이터에서 학습한다!
- 신경망의 특징은 가중치 매개변수의 값을 **데이터**로 보고 **자동으로 결정**함을 의미한다.
  - 이를 통해 사람이 직접 매개변수를 수작업으로 결정하지 않고도 작업이 가능해졌다.

## 1-1. 데이터 주도 학습
- 머신러닝은 사람의 개입을 최소화하고 **수집한 데이터로부터 패턴**을 찾으려 시도한다.
- 머신러닝을 활용하지 않으면 예를 들어 5를 인식하는 목적이라면 알고리즘을 직접 만들어야 한다.
  - 반면 머신러닝은 이미지에서 **특징(feature)를 추출**하고 해당 특징의 **패턴을 머신러닝 기술로 학습**하는 방법을 활용한다.
- 머신러닝의 경우 데이터를 사람이 핸들링 해야하는 영역이 딥러닝보다는 크다.
  - 즉 신경망은 이미지에 포함된 중요한 특징까지 스스로 학습한다.
  - 반면 머신러닝은 어느 정도의 개입이 필요하다.
- 딥러닝은 **종단간 머신러닝(end-to-end machine learning)**이라고도 한다. 즉 처음부터 끝까지 사람의 개입이 없다는 의미이다.
  - 이런 점에서 신경망의 이점은 모든 문제를 같은 맥락에서 풀 수 있다는 장점이 있다.
  - 주어진 데이터를 온전히 학습하고 문제의 패턴을 발견하려 시도한다.

## 1-2. 훈련 데이터와 시험 데이터
- 머신러닝 문제는 **훈련 데이터(training data)**와 **시험 데이터(test data)**로 나눠 학습과 실험을 수행하는 것이 일반적이다.
  - 훈련 데이터만을 사용하여 **최적의 매개변수**를 찾는다.
  - 시험 데이터는 훈련한 모델의 실력을 **평가**한다.
- 훈련과 시험 데이터를 나누는 이유는 모델의 **범용 능력**을 제대로 평가하기 위해서이다.
  - 범용 능력이란 아직 보지 못한 데이터(훈련 데이터에 미포함)로도 문제를 올바르게 풀어내는 능력이다.
- 한 데이터셋에만 지나치게 최적화된 상태를 **과대적합(overfitting)**이라고 한다.

# 2. 손실함수
- 신경망 학습에서는 현재의 상태를 **하나의 지표**로 표현한다.
  - 그리고 해당 지표를 가장 좋게 만들어주는 가중치 매개변수의 값을 탐색한다.
- 이때 신경망 학습에서 사용하는 지표는 **손실 함수(loss function)**이라 한다.
  - 손실 함수는 임의의 함수를 사용할 수도 있지만 일반적으로는 **오차제곱합**과 **교차 엔트로피 오차**를 사용한다.
- 손실 함수는 결국 성능이 얼마나 나쁘냐를 의미한다.
  - 부호만 바꾸면 성능이 얼마나 좋은가에 대한 기준으로 만들 수 있다.

## 2-1. 오차제곱합
- 가장 많이 사용하는 손실 함수는 오차제곱합(sum of squares for error, SSE)로 수식은 다음과 같다.
  - $ y_k $: 신경망의 출력.
  - $ t_k $: 정답 레이블
  - $ k $: 데이터의 차원 수

$$
E = {1 \over 2} \sum_k(y_k-t_k)^2
$$

```python
# 1. 오차제곱합 구현.
def sum_squares_error(y, t):
    return 0.5 * np.sum((y-t)**2)
```

## 2-2. 교차 엔트로피 오차
- 교차 엔트로피 오차(cross-entropy error, CEE)의 수식은 아래와 같다.
  - $ \log $는 밑이 $ e $인 자연로그($ \log_e $)dlek.
  - $ y_k $는 신경망의 출력이다.
  - $ t_k$는 정답 레이블이다.
    - 정답에 해당하는 원소만 1이고 나머지는 0이다. (원-핫 인코딩).
- 다시 말하면 정답일 때의 자연로그를 게산하는 식이다.
- 교차 엔트로피 그래프를 보면 x가 1이되면 y는 0, x가 작아질수록 오차(y)는 음수로 커진다.

$$
E = -\sum_kt_k \log y_k
$$

```python
# 1. 교차 엔트로피 구현 함수.
def cross_entropy_error(y, t):
    delta = 1e-7
    return -np.sum(t * np.log(y + delta))
```

## 2-3. 미니배치 학습
- 머신러닝 문제는 훈련 데이터에 대한 손실 함수의 값을 구하고 해당 값을 최소화하는 매개변수를 찾는다.
  - 데이터가 100개가 있다면 100개의 데이터에 대한 100개의 손실함수 값이 나온다.
- 앞서는 단일 데이터에 관한 교차 엔트로피 오차이다. 이를 모든 데이터에 관한 식으로 변환하면 아래와 같다.
  - $ N $: 데이터의 총 수
  - $ t_{nk} $: $ n $번째 데이터의 $ K $번째 값을 의미한다. (정답 레이블)
  - $ y_{nk} $: 신경망의 출력을 의미한다.
- $ N $으로 나누는 이유는 **정규화**를 하는 목적으로 전체 훈련 데이터의 수와 관계없이 **통일된 지표**를 얻기 위해서이다.

$$
E = -{1 \over N}\sum_n\sum_kt_{nk}\log y_{nk}
$$

- 다만 데이터의 수가 늘어날수록 손실 함수의 합을 구하는데 시간이 오래 걸리기 때문에 데이터의 일부를 추려 **근사치**를 활용할 수 있다.
  - 신경망 학습에서 훈련 데이터의 일부를 골라 학습을 수행하는 방법을 **미니배치 학습**이라 한다.
  - 미니배치 학습에 사용되는 일부 선택된 데이터는 **미니배치(mini-batch)**라 한다.

```python
# 1. 미니배치를 추출하는 함수.
import sys, os
sys.path.append(os.path.join(os.path.dirname(__file__), '..'))
import numpy as np
from dataset.mnist import load_mnist

(x_train, t_train), (x_test, t_test) = \
    # one_hot_label을 하는 이유는 정답 위치의 원소만 1인 배열을 얻기 위해서 이다.
    load_mnist(normalize=True, one_hot_label=True)

print(x_train.shape)  # (60000, 784)
print(t_train.shape)  # (60000, 10)
```

```python
# 배치 크기

# 배치 마스크 생성 총 데이터 크기 중 배치 크기만큼 추출. (인덱스)
```

## 2-4. (배치용) 교차 엔트로피 오차 구현하기
- 미니배치의 교차 엔트로피 오차를 구할 때에는 배치 단위로 나누어 주는 방법을 활용한다.
  - 즉 정규화에 사용하는 데이터의 크기만 달라진다.

```python
# 1. 미니배치의 교차 엔트로피 오차.
def cross_entropy_error(y, t):
    if y.ndim == 1:
        t = t.reshape(1, t.size)
        y = y.reshape(1, y.size)
    
    # 신경망 출력인 y의 1차원이 배치에 사용되는 데이터의 수이다.
    batch_size = y.shape[0]
    return -np.sum(t * np.log(y + 1e-7)) / batch_size
```

```python
# 2. 원-핫 인코딩이 아닐 때 교차 엔트로피 오차.
def cross_entropy_error(y, t):
    if y.ndim == 1:
        t = t.reshape(1, t.size)
        y = y.reshape(1, y.size)

    batch_size = y.shape[0]
    
    # t가 0인 원소는 교차 엔트로피 오차도 0이므로 무시한다.
    # 즉 정답에 해당하는 경우만 계산한다.
    return -np.sum(np.log(y[np.arange(batch_size), t] + 1e-7)) / batch_size
```

## 2-5. 왜 손실 함수를 설정하는가?
- 정확도 대신 손실 함수의 값을 사용하는 이유는 **미분**의 역할 때문이다.
  - 손실 함수의 값을 가능한 작게하는 매개변수를 찾고 해당 매개변수의 **미분**을 계산한 결과를 단서로 매개변수의 값을 **서서히 갱신**하는 과정을 반복한다.
- 하나의 가중치 매개변수의 손실 함수의 미분이 갖는 의미는 **해당 가중치 매개변수의 값을 아주 조금 변화 시켰을 때 손실 함수가 어떻게 변하는가** 이다.
  - 따라서 미분 값을 증가 시키거나 감소 시키면서 손실 함수의 값을 작게 조정한다.
  - 미분 값이 0이되는 시점에는 어느 쪽으로 움직여도 손실 함수의 값이 줄어들지 않는다.
- 정확도(accuracy)를 지표로 사용하지 않는 이유는 **미분 값이 대부분의 장소에서 0**이 되어 매개변수를 갱신할 수 없기 때문이다.
  - 정확도는 손실함수와 같이 연속적으로 변화하기보다 **불연속적**으로 변화하기 때문이다.
  - 정확도가 연속적이지 않은 이유는 연산 과정에서 **argmax**나 **임곗값 판정**이 들어가기 때문이다.
- 정확도와 마찬가지 이유로 불연속적으로 변하는 **계단 함수**를 활성화 함수로 사용하지 않는다.
- 불연속이라는 의미는 기울기가 0임을 의미한다. 즉 미분값이 0이기 때문에 신경망의 학습(매개변수 조정)에 도움을 주지 못한다.

# 3. 수치미분
## 3-1. 미분
- 마라톤 선수가 10분에 2km를 달린다고 하였을 때 속도는 0.2km가 된다. 하지만 이는 **평균 속도**이다.
- 미분은 특정 **순간의 변화량**을 의미한다.따라서 가능한 구간(10분)을 한 순간으로 줄여 변화량을 얻는다.
- 한 순간의 변화량을 수식으로 표현하면 다음과 같다.
  - $ {df(x)\over dx} $: $ f(x) $의 $ x $에 대한 미분을 나타낸다. 즉 $ x $의 변화가 $ f(x) $에 미치는 영향이다.
  - $ \lim_{h\to 0} $: 시간을 의미하는 $ h $를 한없이 $ 0 $에 가깝게한다.
- 미분을 코드로 구현할 때에는 다음 두 가지를 주의해야 한다.
  - 차감되는 $ h $를 너무 작게하면 **반올림 오차(rounding error)** 문제가 발생한다.
    - 즉 너무 작은 소수점은 생략되어 정확한 계산이 불가하다.
    - Python에서는 약 $ 10^{-4} $ 정도를 권장한다.
  - $ (x + h) $와 $ (x - h) $ 두 경우를 모두 고려해야 한다.
    - 이를 **중심 차분** 혹은 **중앙 차분**이라 한다.
    - $ (x + h) $와 $ x $의 차분은 전방 차분이라 한다.
- 아주 작은 차분으로 미분하는 것을 **수치 미분**이라 한다. 
  - 반면 수식을 전개해 미분하는 것은 **해석적(analytic)**으로 미분하다 혹은 해석적 해 등으로 표현한다.
    - $ y = x^2 $는 해석적으로 $ {{dy} \over {dx}} = 2x $이며 **오차를 포함하지 않는 진정한 미분 값**을 구해준다.

$$
{df(x)\over dx} = \lim_{h\to 0}{f(x+h)-f(h)\over h}
$$

```python
# 1. 나쁜 미분 구현 예.
def numerical_diff(f, x):

    # 문제점 1. 반올림 오차 문제
    h = 1e-50

    # 문제점 2. 차분 문제
    return (f(x + h) - f(x)) / h
```

```python
# 2. 옳바른 미분 구현. (DL_from_floor/ch04/gradient_1d.py)
def numerical_diff(f, x):
    h = 1e-4  # 0.0001
    return (f(x + h) - f(x - h)) / (2 * h)
```

## 3-3. 편미분
- 이번에는 아래와 같이 변수가 두 개인 식을 다룬다.
- 함수의 그래프는 그물망과 같은 3차원으로 그려진다(p126).
- 변수가 2개이기 때문에 $ x_0 $과 $ x_1 $ 중 **어느 변수**에 대한 미분을 할 것인지 **구분**해야 한다.
  - 위처럼 변수가 여럿인 함수에 대한 미분을 **편미분**이라 하며 $ \frac{\partial f}{\partial x_0} $나 $ \frac{\partial f}{\partial x_1} $과 같이 표기한다.

$$
f(x_0, x_1)=x^2_0 + x^2_1
$$

```python
# 1. 상단의 식을 함수로 구현.

    return x[0]**2 + x[1]**2
    # 또는 return np.sum(x**2)
```

```python
# 2. x0=3, x1=4일때 x0에 대한 편미분.

def function_tmp1(x0):

# 미분 함수에 대입.
numerical_diff(function_tmp1, 3.0)
```

# 4. 기울기
- $ x_0 $과 $ x_1 $의 편미분을 동시에 계산하고 싶은 경우 $ \left( \frac{\partial f}{\partial x_0}, \frac{\partial f}{\partial x_1}\right) $로 묶어 계산한다고 볼 수 있다. 이때 이렇게 모든 변수의 편미분을 **벡터**로 정리한 것을 기울기(gradient)라 한다.
- 기울기에 대한 시각화는 DL_from_floor/ch04/gradient_2d.py에 있다.
  - 기울기의 그림은 방향을 가진 **벡터(화살표)**로 그려진다.
  - 기울기가 기리키는 쪽은 각 장소에서 **함수의 출력 값을 가장 크게 줄이는 방향**이다.

```python
# 1. 벡터로 기울기를 구현.
def numerical_gradient(f, x):
    h = 1e-4  # 0.0001

    # x와 형상이 같은 배열을 생성 (원소가 모두 0)
    grad = np.zeros_like(x)

    for idx in range(x.size):
        tmp_val = x[idx]

        # f(x+h) 계산
        x[idx] = tmp_val + h
        fxh1 = f(x)

        # f(x-h) 계산
        x[idx] = tmp_val - h
        fxh2 = f(x)

        grad[idx] = (fxh1 - fxh2) / (2*h)
        x[idx] = tmp_val  # 값 복원
    
    return grad

# (3, 4)의 기울기
numerical_gradient(function_2, np.array([3.0, 4.0]))

# (0, 2)의 기울기
numerical_gradient(function_2, np.array([0.0, 2.0]))

# (3, 0)의 기울기
numerical_gradient(function_2, np.array([3.0, 0.0]))
```

## 4-1. 경사법(경사 하강법)
- 매개변수의 공간은 광대하고 어디가 최솟값이 되는지를 짐작하기 어렵다. 이런 상황에서 기울기를 이용해 **함수의 최솟값(혹은 가능한 한 작은 값)을 찾는 기법**이 **경사법**이다.
- 각 지점에서 함수의 값을 낮추는 방향을 제시하는 지푠는 기울기이지만 기울기가 가리키는 방향에 **최솟값이 없는 경우**가 대부분이다.s
  - 함수의 극솟값, 최솟값, 또 안정점(saddle point)이 되는 장소에서 기울기는 0이다.
  - 기울기가 0이긴하지만 반드시 최솟값이라 할 수 없다.
  - 복잡하고 찌그러진 모양의 함수의 경우 평평한 곳으로 파고들면서 고워(플래도, plateau)이라 하는 학습이 진행되지 않는 정체기에 빠질 수 있다.
- 경사법(gradient method)은 현 위치에서 기울어진 방향으로 일정 거리만큼 이동한다.
  - 이후 이동한 지점에서 또 기울기를 구하고 나아가는 과정을 반복한다.
  - 경사법은 머신러닝 모델과 신경망 학습에 자주 사용한다.
- 경사법은 최솟값을 찾느냐, 최댓값을 찾느냐에 따라 이름이 다르다. 최솟값을 찾는 경우 경사 하강법(gradient descent method), 최댓값을 찾는 경우 경사 상승법(gradient ascent method)라 한다.
- 경사법을 수식으로 나타내면 다음과 같다.
  - $ \eta $: 에타는 **갱신하는 양**을 의미하며 이를 신경망 학습에서는 **학습률(learning rate)**이라 한다.
    - 한 번의 학습으로 얼마나 학습해야할지, 즉 매개변수를 얼마나 업데이트할지 결정한다.
    - 변수가 더 늘어도 방식은 동일하다.
    - 일반적으로 0.01이나 0.001 등 미리 특정 값을 정하며 값이 너무 크거나 작으면 적절한 해를 찾기 어렵다.
- 경사법을 수행하고 시각화를 하면 값이 가장 낮은 장소인 원점에 점차 가까워지는 것을 볼 수 있다. (DL_from_floor/ch04/gradient_method.py)
- 학습률과 같은 매개변수를 **하이퍼파라미터(hyper parameter)**라고 한다.
  - 가중치와 편향과 같은 신경망 매개변수와 다르게 하이퍼파라미터는 **사람이 직접 설정**하는 매개변수이다.

$$
x_0 = x_0 - \eta \frac{\partial f}{\partial x_0}
$$

$$
x_1 = x_1 - \eta \frac{\partial f}{\partial x_1}
$$

```python
# 1. 경사법 구현.
# f: 최적화하려는 함수 / init_x: 초깃값
# lr: learning rate / step_num: 반복 횟수
def gradient_descent(f, int_x, lr=0.01, step_num=100):
    x = init_x

    for i in range(step_num):
        grad = numerical_gradient(f, x)
        x -= lr * grad
    return x
```

```python
# 2. 경사법 테스트
def function_2(x):
    return x[0]**2 + x[1]**2

init_x = np.array([-3.0, 4.0])
gradient_descent(function_2, init_x=init_x, lr=0.1, step_num=100)
```

```python
# 3. 학습률에 따른 결과 차이.
# 학습률이 너무 큰 예: lr=10.0
init_x = np.array([-3.0, 4.0])
gradient_descent(function_2, init_x=init_x, lr=10.0, step_num=100)

# 학습률이 너무 작은 예: lr=1e-10
```

## 4-2. 신경망에서의 기울기
- 신경망 학습에서도 가중치 매개변수에 대한 손실 함수의 기울기를 구해야한다.
- 예를 들어 형상이 2 x 3, 가중치가 $ W $, 손실 함수가 $ L $인 신경망의 경사는 $ \frac{\partial L}{\partial W} $로 나타낼 수 있다. 수식은 아래와 같다. (DL_from_floor/ch04/gradient_simplenet.py)
  - $ W $: 가중치
  - $ L $: 손실 함수, 각 원소는 $ w $을 변경했을 때에 대한 $ L $의 변화량을 보여주는 편미분이다.
- 파이썬 함수를 $ f(x) $로 넘기는데 이 대신 **람다(lambda)**를 사용하면 더 짧게 구현이 가능하다.

$$
W = 
\begin{pmatrix} 
w_{11} & w_{12} & w_{13} \\
w_{21} & w_{22} & w_{23}
\end{pmatrix}
$$

$$
\frac{\partial L}{\partial W} = 
\begin{pmatrix}
\frac{\partial L}{\partial w_{11}} & \frac{\partial L}{\partial w_{12}} & \frac{\partial L}{\partial w_{13}} \\
\frac{\partial L}{\partial w_{21}} &\frac{\partial L}{\partial w_{22}} & \frac{\partial L}{\partial w_{23}}
\end{pmatrix}
$$

```python
# 1. 람다 구현의 예.
f = lambda w: net.loss(x, t)
dW = numerical_gradient(f, net.W)
```
