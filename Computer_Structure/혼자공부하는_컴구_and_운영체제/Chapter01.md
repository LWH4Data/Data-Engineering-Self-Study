<h1>1. 컴퓨터 구조를 알라야 하는 이유</h1>
<h2>1-1. 문제 해결</h2>
<ul>
  <li>
    컴퓨터 구조를 이해하고 있다면 상황을 빠르게 진단하고 문제 해결의 실마리를 다양하게 찾을 수 있다. 컴퓨터는 미지의 대상이 아닌 <strong>분석의 대상</strong>이 된다.
  </li>
</ul>

<br>

<h2>1-2. 성능, 용량, 비용</h2>
<ul>
  <li>
    컴퓨터 구조를 이해를 통해 입력과 출력에만 국한되지 않고 성능, 용량, 비용까지 고려할 수 있는 역량을 갖출 수 있음을 강조한다.
  </li>
</ul>

<br><br>

<h1>2. 컴퓨터 구조의 큰 그림</h1>
<ul>
  <li>
    알아야할 컴퓨터 구조 지식은 크게 두 가지이다. 하나는 <strong>컴퓨터가 이해하는 정보</strong>이고 다른 하나는 <strong>컴퓨터의 네 가지 핵심 부품</strong>이다.
  </li>
</ul>

<br>

<h2>2-1. 컴퓨터가 이해하는 정보</h2>
<ul>
  <li>
    컴퓨터는 0과 1로 표현된 정보만을 이해하며 이렇게 0과 1로 표현되는 정보는 크게 <strong>데이터</strong>와 <strong>명령어</strong> 두 가지이다.
  </li>
    <ul>
      <li>
        컴퓨터가 이해하는 숫자, 문자, 이미지, 동영상과 같은 정보를 데이터라 한다.
      </li>
      <li>
        데이터가 명령어 없이는 아무것도 못하는 정보 덩어리일 뿐이라면 명령어(instruction)는 <strong>데이터를 움직이고 컴퓨터를 작동시키는 정보</strong>이다.
      </li>
    </ul>
  <li>
    명령어는 컴퓨터를 동작시키는 정보이고, 데이터는 명령어를 위해 존재하는 일종의 재료이다. 이런 점에서 컴퓨터는 <strong>명령어들의 모음</strong>으로 정의되기도 한다.
  </li>
</ul>

<br>

<h2>2-2. 컴퓨터의 4가지 핵심 부품</h2>
<ul>
  <li>
    다양한 종류의 컴퓨터가 있으나 외관과 용도를 막론하고 컴퓨터의 핵심 부품은 다음 네 가지이다.
  </li>
    <ul>
      <li>
        중앙처리장치(CPU, Central Processing Unit)
      </li>
      <li>
        주기억장치(main memory)
      </li>
        <ul>
          <li>
            RAM(Random Access Memory)
          </li>
            <ul>
              <li>
                일반적으로 메모리라 칭하는 주기억장치이다.
              </li>
              <li>
                더 중요한 주기억장치이며 도서에서 언급하는 주기억장치는 별도 설명이 없다면 RAM이다.
              </li>
            </ul>
          <li>
            ROM(Read Only Memory)
          </li>
        </ul>
      <li>
        보조기억장치(secondary storage)
      </li>
      <li>
        입출력장치(input/ouptut device)
      </li>
    </ul>
  <li>
    네 가지 핵심 부품의 큰 그림 그리기
  </li>
    <ul>
      <li>
        1. 가장 큰 사각형은 메인보드이다.
      </li>
      <li>
        2. 메인보드 안에는 시스템 버스가 존재한다.
      </li>
      <li>
        3. CPU는 메인보드 내부에 위치하며 내부에는 ALU(산술논리연산자), 제어장치와 여러 레지스터가 존재한다. 그리고 시스템 버스와 연결되어 있다.
      </li>
      <li>
        4. 메모리는 메인보드 내부에 위치하며 메인보드 내의 시스템 버스와 연결되어 있다.
      </li>
      <li>
        5. 보조기억장치는 메인모드 외부에 존재하며 메인보드 내부의 시스템 버스와 연결되어 있다.
      </li>
      <li>
        6. 모니터, 키보드, 마우스 등은 메인보드 외에 위치하며 메인보드 내의 시스템 버스와 연결되어 있다.
      </li>
    </ul>
</ul>

<h3>2-2-1. 메모리</h3>
<ul>
  <li>
    메모리는 현재 실행되는 프로그램의 명령어와 데이터를 <strong>저장하는 부품</strong>이다.
  </li>
    <ul>
      <li>
        다시 말하면 프로그램이 실행되기 위해서는 반드시 명령어와 데이터가 <strong>메모리에 저장</strong>되어 있어야 한다.
      </li>
    </ul>
  <li>
    메모리에 저장된 명령어와 데이터를 빠르게 가져오기 위해 <strong>정돈</strong>이 되어 있어야 한다. 따라서 메모리는 저장된 값을 빠르고 효울적으로 접근하기 위해 <strong>주소(address)</strong>라는 개념을 사용한다.
  </li>
  <li>
    겉보기에는 명령어와 데이터가 모두 0과 1로 표현되기 때문에 <strong>0과 1로 이루어진 데이터</strong>를 저장한 것처럼 보이게 된다.
  </li>
  <li>
    기억할 것 세 가지
  </li>
    <ul>
      <li>
        프로그램이 실행되기 위해서는 반드시 <strong>메모리에 저장</strong>되어 있어야 한다.
      </li>
      <li>
        메모리는 현재 실행되는 프로그램의 <strong>명령어</strong>와 <strong>데이터</strong>를 저장한다.
      </li>
      <li>
        메모리에 저장된 값의 위치는 <strong>주소</strong>로 알 수 있다.
      </li>
    </ul>
</ul>

<h3>2-2-2. CPU</h3>
<ul>
  <li>
    CPU는 컴퓨터의 두뇌로서 다음의 역할을 한다.
  </li>
    <ul>
      <li>
        메모리에 저장된 명령어를 읽는다.
      </li>
      <li>
        읽어 들인 명령어를 해석하고 실행한다.
      </li>
    </ul>
  <li>
    CPU의 내부 구성 요소
  </li>
    <ul>
      <li>
        <strong>산술논리연산장치(ALU, Arithmetic Logic Unit)</strong>
      </li>
        <ul>
          <li>
            쉽게 말해 <strong>계산기</strong>이다.
          </li>
          <li>
            컴퓨터 내부에서 수행되는 대부분의 계산을 수행한다.
          </li>
        </ul>
      <li>
       <strong>레지스터</strong>
      </li>
        <ul>
          <li>
            CPU 내부의 <strong>작은 임시 저장 장치</strong>이다.
          </li>
          <li>
            프로그램을 실행하는 데 필요한 값들을 임시로 저장한다.
          </li>
          <li>
            CPU 내에는 <strong>다수의 레지스터</strong>가 존재하며 각기 <strong>다른 이름</strong>과 <strong>역할</strong>을 가지고 있다.
          </li>
        </ul>
      <li>
        <strong>제어장치(CU, Control Unit)</strong>
      </li>
        <ul>
          <li>
            <strong>제어 신호(control signal)</strong>라는 전기 신호를 내보내고 명령어를 해석하는 장치이다.
          </li>
            <ul>
              <li>
                제어 신호란 컴퓨터 <strong>부품들을 관리하고 작동</strong>시키기 위한 일종의 전기 신호이다.
              </li>
              <li>
                CPU가 메모리에 저장된 값을 읽고 싶을 땐 <strong>메모리 읽기</strong>라는 제어 신호를 보낸다.
              </li>
              <li>
                CPU가 메모리에 어떤 값을 저장하고 싶을 땐 메모리를 향해 <strong>메모리 쓰기</strong>라는 신호를 보낸다.
              </li>
            </ul>
        </ul>
    </ul>
  <li>
    CPU 작업 순서 예시.
  </li>
    <ul>
      <li>
        CPU의 제어 장치가 메모리에 저장된 명령어를 읽기위해 메모리 읽기 제어 신호를 보낸다.
        <br>➡️ 메모리는 1번지에 저장된 명령어를 CPU에 건네준다.
        <br>➡️ CPU는 건네받은 명령어를 레지스터에 저장한다.
        <br>➡️ 제어 장치는 레지스터에 저장된 명령어를 해석하고 다시 필요한 데이터를 메모리를 얻기 위해 메모리 읽기 제어 신호를 보낸다.
        <br>➡️ 메모리는 제어 신호에 맞추어 필요한 데이터를 CPU에 건네준다.
        <br>➡️ CPU는 메모리에서 받은 데이터를 서로 다른 레지스터에 저장한다.
        <br>➡️ 마침내 ALU는 읽어들인 데이터로 연산을 수행하며 결괏값 또한 레지스터에 다른 레지스터에 저장한다.
        <br>➡️ 계산이 완료되었다면 명령어의 실행이 끝난다.
      </li>
    </ul>
  <li>
    CPU에 관해 기억할 세 가지
  </li>
    <ul>
      <li>
        CPU는 메모리에 저장된 값을 읽어 들이고, 해석하고, 실행하는 장치이다.
      </li>
      <li>
        CPU 내부에는 ALU, 레지스터, 제어장치가 있다.
      </li>
      <li>
        ALU는 계산하는 장치, 레지스터는 임시 저장 장치, 제어장치는 제어 신호를 발생시키고 명령어를 해석하는 장치이다.
      </li>
    </ul>
</ul>

<h3>2-2-3. 보조기억장치</h3>
<ul>
  <li>
    메모리에는 두 가지 치명적인 단점이 존재한다.
  </li>
    <ul>
      <li>
        첫 번째: 가격이 비싸 저장 용량이 적다.
      </li>
      <li>
        두 번째: 전원이 꺼지면 저장된 내용을 잃는다.
      </li>
        <ul>
          <li>
            실행 중인 프로그램들은 메모리에 저장되기 때문이다.
          </li>
        </ul>
    </ul>
  <li>
    보조기억장치는 메모리보다 용량이 크고 전원이 꺼져도 내용을 잃지 않는 메모리를 보조하는 저장 장치이다.
  </li>
    <ul>
      <li>
        하드 디스크, SSD, USB 메모리, DVD, CD-ROM 등이 보조기억장치의 예이다.
      </li>
    </ul>
  <li>
    메모리가 <strong>현제 실행되는 프로그램</strong>을 저장한다면, 보조기억장치는 <strong>보관할 프로그램을 저장</strong>한다 생각할 수 있다.
  </li>
</ul>

<h3>2-2-4. 입출력장치</h3>
<ul>
  <li>
    입출력장치는 마이크, 스피커, 프린터, 마우스, 키보드와 같이 <strong>컴퓨터 외부</strong>에 연결되어 <strong>컴퓨터 내부와 정보를 교환</strong>하는 장치이다.
  </li>
  <li>
    보조기억장치도 입출력장치의 일종으로 볼 수도 있으며 이런 경우에는 컴퓨터 주변에 붙어있는 장치를 통칭하는 용어인 <strong>주변장치(peripheral devie)</strong>라 통칭하기도 한다.
  </li>
    <ul>
      <li>
        많은 전공 서적들은 이를 구분해서 서술하기에 일반적으로 구분해서 사용한다 보면된다.
      </li>
    </ul>
</ul>

<h3>2-2-5. 메인보드와 시스템 버스</h3>
<ul>
  <li>
    앞서 설명한 컴퓨터의 핵심 부분들은 모두 <strong>메인보드(main board)</strong>에 연결된다.
  </li>
    <ul>
      <li>
        메인보드는 <strong>마더보드(mother board)</strong>라고도 한다.
      </li>
      <li>
        메인보드에는 여러 컴퓨터 부품을 부착할 수 있는 <strong>슬롯</strong>과 <strong>연결 단자</strong>가 있다.
      </li>
    </ul>
  <li>
    메인보드에 연결된 부품들은 서로 정볼르 주고 받을 때 메인보드 내부의 <strong>버스(bus)</strong>라는 통로를 이용한다.
  </li>
    <ul>
      <li>
        컴퓨터 내부에는 <strong>다양한 종류의 버스</strong>가 존재한다.
      </li>
    </ul>
  <li>
    여러 버스 중 컴퓨터의 네 가지 핵심 부품을 연결하는 가장 중요한 버스는 <strong>시스템 버스(system bus)</strong>이다.
  </li>
  <li>
    시스템 버스는 주소 버스, 데이터 버스, 제어 버스로 구성되어 있다.
  </li>
    <ul>
      <li>
        <strong>주소 버스(address bus)</strong>: 주소를 주고받는 통로.
      </li>
      <li>
        <strong>데이터 버스(data bus)</strong>: 명령어와 데이터를 주고받는 통로.
      </li>
      <li>
        <strong>제어 버스(control bus)</strong>: 제어 신호를 주고받는 통로.
      </li>
        <ul>
          <li>
            CPU의 구성 요소 중 하나인 제어장치는 제어 버스를 통해 신호를 주고받는다.
          </li>
        </ul>
    </ul>
  <li>
    실행 흐름 예.
  </li>
    <ul>
      <li>
        CPU는 제어 버스로 메모리 읽기 신호를, 주소 버스로 읽고자 하는 주소를 보낸다.
        <br>➡️ 메모리는 데이터 버스로 CPU가 요청한 주소에 있는 내용을 본낸다.
      </li>
    </ul>
</ul>
