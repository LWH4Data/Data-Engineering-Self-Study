<h1>1. 운영체제를 알아야 하는 이유</h1>
<h2>1-1. 운영체제란</h2>
<ul>
  <li>
    모든 프프로그램들은 실행에 있어 CPU, 하드 디스크 등 하드웨어를 필요로 하며 이러한 필요 요소들을 <strong>시스템 자원</strong> 혹은 줄여서 <strong>자원</strong>이라 한다.
  </li>
  <li>
    실행할 프로그램에 <strong>필요한 자원을 할당</strong>하고, 프로그램이 <strong>올바르게 실행</strong>되도록 돕는 특별한 프로그램이 <strong>운영체제(operating system)</strong>이다.
  </li>
  <li>
    운영체제 또한 프로그램이기 때문에 실행되기 위해서는 <strong>메모리에 적재</strong>되어야 한다.
  </li>
    <ul>
      <li>
        다만 특별한 프로그램이기 때문에 항상 컴퓨터가 부팅 될 때 메모리 내 <strong>커널 영역(kernel space)</strong>라는 공간에 따로 적재되어 실행된다.
      </li>
      <li>
        커널 영역 외에 나머지 영역과 사용자가 이용하는 응용 프로그램이 적재되는 영역을 <strong>사용자 영역(user space)</strong>이라 한다.
      </li>
      <li>
        운영체제는 커널 영역에 적재되어 사용자 영역에 적재된 프로그램들이 자원을 할당하고 올바르게 실행되도록 돕는다.
      </li>
    </ul>
  <li>
    운영체제는 실행할 프로그램을 메모리에 적재하고, 더 이상 실행되지 않는 프로그램을 메모리에서 삭제하며 지속적으로 <strong>메모리 자원을 관리</strong>한다.
  </li>
    <ul>
      <li>
        최대한 공정하게 여러 프로그램에 <strong>CPU 자원을 할당</strong>한다.
      </li>
      <li>
        동시에 응용 프로그램이 프린터에 접근하는 등 중복되는 활동을 할 때에도 이를 <strong>조율</strong>한다.
      </li>
      <li>
        즉 <strong>응용 프로그램과 하드웨어 사이</strong>에서 응용 프로그램에 필요한 자원을 할당하고, 올바르게 실행되도록 한다.
      </li>
    </ul>
  <li>
    운영체제는 관리할 <strong>자원별로 기능</strong>이 나누어져 있다. 예를 들어 운영체제의 특정 부분은 CPU를, 어느 한 부분은 메모리를, 또 다른 부분은 하드 디스크를 관리하는 등이다.
  </li>
</ul>

<br>

<h2>1-2. 운영체제를 알아야 하는 이유</h2>
<ul>
  <li>
    운영체제가 없다면 하드웨어를 조작하는 코들를 개발자가 모두 직접 작성해야 한다.
  </li>
  <li>
    운영체제는 하드웨어와 가장 긴밀하게 소통하기 때문에 프로그램을 잘 다루기 위해서는, 즉 문제 해결을 잘 하기 위해서는 운영체제를 알아두는 것이 프로그램을 더 깊게 이해할 수 있으며 따라서 운영체제를 알아두는 것은 중요하다.
  </li>
    <ul>
      <li>
        대표적인 예로는 <strong>오류 메시지</strong>가 있다. 하드웨어가 제대로 실행하지 못하면 운영체제는 오류 메시지를 띄워 보여준다.
      </li>
      <li>
        프로그래밍 문법만 학습하는 경우 운영체제의 메시지를 이해하기 어렵고, 이는 문제의 진전과 해결에도 어려움과도 연결된다.
      </li>
    </ul>
</ul>

<br><br>

<h1>2. 운영체제의 큰 그림</h1>
<h2>2-1. 운영체제의 심장, 커널</h2>
<ul>
  <li>
    운영체제는 현존하는 프로그램 중 <strong>규모가 가장 크며</strong> 운영체제의 서비스 또한 <strong>매우 다양</strong>하다.
  </li>
    <ul>
      <li>
        자원에 접근하고 조작하는 기능, 프로그램이 올바르고 안전하게 실행되게 하는 기능이 운영체제의 핵심 서비스이다.
      </li>
    </ul>
  <li>
    운영체제의 핵심 서비스를 담당하는 부분을 <strong>커널(kernel)</strong>이라 한다.
  </li>
    <ul>
      <li>
        운영체제가 설치된 모든 기기에는 커널이 있다.
      </li>
      <li>
        어떤 커널을 사용하는지에 따라 실행하고 개발하는 프로그램이 하드웨어를 이용하는 양상이 달라지고 결과적으로 전체 컴퓨터의 성능도 달라질 수 있다.
      </li>
    </ul>
  <li>
    운영체제가 제공하는 서비스 중 커널에 포함되지 않는 서비스도 있는데, 대표적으로 <strong>사용자 인터페이스(UI, User Interface)</strong>가 속한다.
  </li>
    <ul>
      <li>
        사용자 인터페이스의 종류에는 <strong>그래픽 유저 인터페이스(GUI: Graphical User Interface)</strong>와 <strong>커맨드 라인 인터페이스(CLI: Command Line Interface)</strong>가 있다.
      </li>
        <ul>
          <li>
            그래픽 유저 인터페이스는 바탕화면이나 스마트폰의 화면과 같은 <strong>그래픽</strong>을 기반으로 컴퓨터와 상호작용할 수 있는 인터페이스이다.
          </li>
          <li>
            커맨드 라인 인터페이스는 <strong>명령어</strong>를 기반으로 컴퓨터와 상호작용할 수 있는 인터페이스이다.
          </li>
        </ul>
      <li>
        따라서 같은 커널을 사용하더라도 사용자 인터페이스는 다를 수 있다.
      </li>
    </ul>
</ul>
