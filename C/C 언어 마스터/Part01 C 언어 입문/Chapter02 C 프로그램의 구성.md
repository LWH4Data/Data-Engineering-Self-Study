<h1>1. C 프로그램의 구성 요소</h1>
<h2>1-1. C 프로그램의 기본 구조</h2>
<ul>
  <li>
    절차적 프로그래밍 언어인 C 언어는 프로그램을 <strong>여러 함수의 집합</strong>으로 구성하여 각 함수가 작업을 수행하는 데 중점을 두며 기본적인 구조는 다음과 같다.
  </li>
    <ul>
      <li>
        <strong>헤더 파일</strong>: 프로그램에서 사용할 표준 라이브러리나 다른 라이브러리를 포함하고 있다. 대표적인 전처리기인 #include &lt;stdio.h&gt;는 표준 입출력 함수를 사용한다.
      </li>
      <li>
        <strong>함수 정의</strong>: C 프로그램은 하나 이상의 함수로 구성된다. main() 함수는 모든 C 프로그램의 진입점으로 프로그램 실행 시 가장 먼저 호출된다.
      </li>
      <li>
        <strong>변수 선언</strong>: 프로그램에서 사용될 변수를 선언한다. C 언어에서는 변수를 사용하기 전에 변수의 자료형을 먼전 선언해야 한다.
      </li>
      <li>
        <strong>실행문</strong>: 프로그램이 작업하는 수행 과정과 로직으로 구성된 코드영역이다. 제어, 반복, 함수 호출 등이 포함될 수 있다.
      </li>
    </ul>
</ul>

<br>

<h2>1-2. 전처리기</h2>
<ul>
  <li>
    코드를 컴파일 과정에 맞춰 조정하고 변환하는 역할을 한다.
  </li>
    <ul>
      <li>
        예를 들어 #include &lt;stdio.&gt;라면 코드 실행 전에 &lt;stdio.&gt; 헤더 파일의 내용을 현재 소스 코드에 포함하라는 지시를 컴파일러에 내린다.
      </li>
      <li>
        <strong>#include</strong>는 일반적으로 라이브러리 함수, 매크로 정의, 전역변수 등의 <strong>정보가 담긴 파일을 포함</strong>할 때 사용하는 지시문이다.
      </li>
        <ul>
          <li>
            &lt;stdio.&gt;와 같은 코드를 <strong>헤더 파일(header file)</strong>이라 부른다. 이는 코드를 <strong>별도의 파일에 정의</strong>하고 필요할 때마다 사용하여 코드의 중복을 줄이면서 프로그램의 구조를 체계적으로 관리할 수 있게 해준다.
          </li>
        </ul>
    </ul>
</ul>

<br>

<h2>1-3. main() 함수</h2>
<ul>
  <li>
    main() 함수는 <strong>C 프로그램의 시작점</strong>이다. 운영체제가 프로그램을 실행할 때 함수가 자동으로 호출된다.
  </li>
    <ul>
      <li>
        C 언어를 함수 기반의 언어라 칭할 때의 이 함수가 main()을 의미하기도한다.
      </li>
    </ul>
  <li>
    <strong>함수(function)</strong>는 수학에서의 함수와 비슷한 개념으로 특정한 작업을 수행하도록 설계된 독립적인 코드 블록이다.
  </li>
  <li>
    다음 장부터의 코드는 int main()으로 고정하여 작성한다.
  </li>
</ul>

<h4>return 0과 return 1</h4>
<ul>
  <li>
    전통적으로 main() 함수에서는 프로그램이 <strong>정상적으로 종료</strong>되었음을 운영체제에 알리는 방법으로 <strong>return 0</strong>을 사용한다.
  </li>
  <li>
    return 1은 프로그램이 성공적으로 실행되지 못했음을 의미한다. 일반적으로 프로그램 실행 중에 오류가 발생하거나, 프로그램이 요구사항을 충족하지 못한 경우가 해당한다.
  </li>
</ul>

<br>

<h2>1-4. 주석</h2>
<ul>
  <li>
    주석(comment)은 소스 코드의 이해를 돕는 설명으로 컴파일러가 무시하기 때문에 프로그램 실행에 직접적인 영향을 미치지 않는다.
  </li>
  <li>
    일반적으로 프로젝트의 개선 및 주의 사항 등 개발자가 참고할 내용이나 다른 개발자와 공유할 정보를 기록할 때 사용한다.
  </li>
    <ul>
      <li>
        C 언어는 //와 /* */ 형식의 주석을 지원한다.
      </li>
    </ul>
</ul>

<h1>2. 표준 출력 함수</h1>
<h2>2-1. printf() 함수</h2>
<ul>
  <li>
    printf() 함수는 모니터에 데이터를 출력할 때 사용하는 표준 출력 함수로, 출력 함수 중 가장 기본적인 함수이다.
  </li>
    <ul>
      <li>
        printf()는 &lt;stdio.h&gt; 헤더 파일에 정의되어 있다.
      </li>
      <li>
        printf()를 수행하면 <strong>'메모리 → 표준 출력 버퍼 → 모니터'</strong> 순서로 출력이 이루어진다.
      </li>
        <ul>
          <li>
            표준 출력 버퍼란 프로그램이 출력할 데이터를 임시로 저장하는 메모리 영역이다. 
          </li>
        </ul>
    </ul>
</ul>


<h3>2-1-1. 문자열 출력</h3>
<ul>
  <li>
    C 언어에서 문자열("")을 출력할 때 printf() 함수를 사용한다. printf() 함수는 문자열 외에도 숫자, 부동 소수점 수  등 다양한 유형의 데이터를 형식에 맞게 출력할 수 있다.
  </li>
</ul>

<h3>2-1-2. 정수와 실수 출력</h3>
<ul>
  <li>
    printf() 함수로 값을 출력하려면 기본적인 <strong>형식 지정자</strong>를 활용해야 한다.
  </li>
  <li>
    <strong>형식 지정자(format specifier)</strong>는 printf(), scanf()와 같은 입출력 함수에서 쓰이는 특수 문자로, <strong>출력 데이터의 형식을 지정</strong>하는 데 사용된다.
  </li>
    <ul>
      <li>
        형식 지정자는 <strong>% 기호 뒤에 오는 문자</strong>로 구성된다. (p62).
      </li>
      <li>
        printf("%d", 100)이라면 %d의 자리에 100이 출력된다. 예제 코드는 Practice/Ch02/ex02_02.c에 있다.
      </li>
    </ul>
</ul>

<h3>2-1-3. 변수 출력</h3>
<ul>
  <li>
    printf() 함수에는 형식 지정자 뒤에 값이 아닌 <strong>변수</strong>를 입력으로 줄 수도 있다.
  </li>
  <li>
    printf() 함수에는 두 개 이상의 형식 지정자와 값(혹은 변수)을 할당하여 활용할 수 있지만, 이때에는 순서에 유의해야 한다.
  </li>
  <li>
    예제 코드는 Practice/Ch02/ex02_03.c에 있다.
  </li>
</ul>

<br>

<h2>2-2. printf() 함수의 변환 서식</h2>
<ul>
  <li>
    printf() 함수로 데이터를 출력할 때 % 뒤에 <strong>숫자</strong>를 넣어 출력 필드의 <strong>최소 너비</strong>를 지정할 수 있다.
  </li>
  <li>
    % 뒤에 <strong>마침표(.)</strong>와 함께 <strong>소수점 아래 자릿수</strong>를 제한할 수도 있다.
  </li>
</ul>

<h3>2-2-1. 정수 출력 형식 지정자</h3>

```C
printf("%d\n", 98765);    // 98765
printf("%-d\n", 98765);   // 98765 (왼쪽 정렬)
printf("%10d\n", 98765);  // _____98765 (너비 10, 오른쪽 정렬)
printf("%-10d\n", 98765); // 98765_____ (너비 10, 왼쪽 정렬)
```

<h3>2-2-2. 실수 출력 형식 지정자</h3>

```C
printf("%f\n", 95.12345);      // 95.123450 (기본 소수점 아래 여섯 자리)
printf("%.2\n", 95.12345);     // 95.12
printf("%10f\n", 95.12345);    // _95.123450 (너비 10, 오른쪽 정렬)
printf("%-10f\n", 95.12345);   // 95.123450_ (너비 10, 왼쪽 정렬)
printf("%10.2f\n", 95.12645);  // _____95.13 (소수점 아래 두 자리, 반올림)
printf("%-10.2f\n", 95.12645); // 95.13_____ (소수점 아래 두 자리, 반올림)
```

<h4>형식 지정자와 변환 형식 지정자</h4>
<ul>
  <li>
    <strong>형식 지정자</strong>는 printf()와 같은 함수에 사용되며 출력할 데이터의 형식을 지정하여 <strong>화면에 표시</strong>하는 역할을 한다.
  </li>
  <li>
    <strong>변환 형식 지정자</strong>는 scanf()와 같은 입력 함수에 사용되며 입력받은 데이터의 형식을 정의하고, 입력된 데이터를 <strong>특정 형식으로 변환하여 변수에 저장</strong>한다.
  </li>
</ul>

<h1>3. 표준 입력 함수</h1>
<h2>3-1. scanf() 함수</h2>
<ul>
  <li>
    scanf()는 키보드로 다양한 값을 <strong>입력받을 때</strong> 사용하는 가장 기본적인 함수이며 &lt;stdio.h&gt; 헤더 파일에 정의되어 있다.
  </li>
  <li>
    입력을 할 때에는 <strong>'키보드 → 표준 입력 버퍼 → (scanf()) → 메모리'</strong> 순으로 진행된다.
  </li>
</ul>

<h2>3-2. 키보드 입력</h2>
<ul>
  <li>
    scanf() 함수도 마찬가지로 <strong>형식 지정자</strong>를 사용하여 데이터를 입력받는다.
  </li>
    <ul>
      <li>
        형식 지정자 뒤에는 <strong>&(앰퍼센트)</strong>를 통해 <strong>주소를 지정한 변수</strong>에 값을 입력한다.
      </li>
      <li>
        &는 주소 연산자로 실제 메모리 주소를 알 수 없기 때문에 C 언어에서는 <strong>변수명 앞에 주소 연산자 &</strong>를 붙여 변수의 메모리 주소를 나타낸다.
      </li>
    </ul>
</ul>

<h3>3-2-1. 정수와 실수 입력</h3>
<ul>
  <li>
    scanf("%d", &num); → 입력받은 정수를 변수 num에 저장.
  </li>
  <li>
    scanf("%f", &num); → 입력받은 실수를 변수 num에 저장.
  </li>
</ul>

<h3>3-2-2. 문자와 문자열 입력</h3>

```C
char ch;           // 문자 1개를 저장할 변수 선언
scanf("%c", &ch);  // 문자 1개를 입력받아 변수 ch에 저장.

char str[10];        // 문자 10개를 저장할 변수 선언(배열)
scanf("%s", str);    // 사용자로부터 문자열을 입력받아 변수 str에 저장. (문자열의 끝은 자동으로 null 종료 문자('\0')이 추가됨).
```

<h4>sacnf() 함수 사용 시 주의점</h4>
<ul>
  <li>
    scanf() 함수는 입력된 데이터의 크기를 검사하지 않기 때문에 사용자가 예상보다 많은 데이터를 입력하면 <strong>버퍼 오버플로</strong>가 발생할 수 있다.
  </li>
    <ul>
      <li>
        이와 관련해서는 비주얼 스튜디오 등의 개발 환경에서 컴파일 과정에서 경고를 발생시킨다.
      </li>
    </ul>
</ul>

<h3>3-2-3. 여러 개의 변수 입력</h3>

```C
scanf("%d %c %d", &a, &op, &b);
```
