<h1>1. 컴퓨터 네트워크를 알아야 하는 이유</h1>
<ul>
  <li>
    여러 개의 장치가 마치 그물처럼 서로 연결되어 정보를 주고받을 수 있는 통신망을 컴퓨터 네트워크(computer network)라 한다.
  </li>
</ul>

<br>

<h2>1-1. 네트워크의 네트워크, 인터넷</h2>
<ul>
  <li>
    인터넷(internet)이란 여러 네트워크를 연결한 네트워크의 네트워크이다.
  </li>
    <ul>
      <li>
        여러 장치들이 네트워크에 연결되면 주변 장치 뿐만아니라 네트워크와 연결된 곳이라면 어디든 정보를 주고 받을 수 있다.
      </li>
    </ul>
  <li>
    개발에 있어서도 네트워크를 이용하는 프로그램, 즉 다른 장치와 상호 작용하며 실행되는 프로그램을 개발하는 경우가 많으며 따라서 네트워크에 대해 이해해 두는 것이 좋다.
  </li>
</ul>

<br>

<h2>1-2. 개발자가 컴퓨터 네트워크를 알아야 하는 이유</h2>
<ul>
  <li>
    도서에서는 개발자의 업무를 크게 다음 두 가지로 나눈다. 그리고 네트워크는 두 가지 업무에 모두 도움을 준다.
  </li>
    <ul>
      <li>
        프로그램을 만드는 업무
      </li>
      <li>
        만들어진 프로그램을 유지 보수하는 업무
      </li>
    </ul>
</ul>

<h3>1-2-1. 프로그램을 만드는 업무에서 네트워크 지식을 활용하는 경우</h3>
<ul>
  <li>
    TCP/UDP와 같은 네트워크의 지식, HTTP와 쿠키, DNS, HTTP/HTTPs, 포트 등 다양한 네트워크 지식들을 알고 있는 것이 도움이 된다.
  </li>
</ul>

<h3>1-2-2. 프로그램을 유지 보수하는 업무에서 네트워크 지식을 활용하는 경우</h3>
<ul>
  <li>
    갑자기 인터넷 연결이 안되는 경우, 웹 서버가 갑자기 죽은 경우, 프로그램 유지 보수 등의 경우에서 유용하게 활용할 수 있다.
  </li>
</ul>

<br><br>

<h1>2. 네트워크 거시적으로 살펴보기</h1>
<ul>
  <li>
    네트워크는 여러 장치가 서로 연결되어 정보를 주고 받을 수 있는 통신망이며 모양은 <strong>그래프(graph) 형태</strong>를 띠고 있다.
  </li>
    <ul>
      <li>
        그래프란 <strong>노드(node)</strong>와 노드를 연결하는 <strong>간선(edge)</strong>으로 이루어진 자료 구조이다.
      </li>
    </ul>
</ul>

<br>

<h2>2-1. 네트워크의 기본 구조</h2>
<ul>
  <li>
    모든 네트워크는 <strong>노드</strong>, 노스를 연결하는 <strong>간선</strong>, 노드 간 주고받는 <strong>메시지</strong>로 구성된다.
  </li>
    <ul>
      <li>
        간선은 정보를 주고받을 수 있는 유무선의 통신 매체라 이해하면 쉽다.
      </li>
    </ul>
</ul>

<h3>2-1-1. 호스트</h3>
<ul>
  <li>
    네트워크의 <strong>가장자리에 위치한 노드</strong>는 네트워크를 흐르는 정보를 최초로 생성 및 송신하고, 최종적으로 수진하는데 이러한 가장자리 노드를 네트워크에서는 <strong>호스트(host)</strong>라고 한다.
  </li>
    <ul>
      <li>
        호스트는 네트워크의 가장자리에 자리 잡고 있다는 점에서 <strong>종단 시스템(end system)</strong>이라고도 한다.
      </li>
    </ul>
  <li>
    때로는 호스트가 네트워크에서 특정한 역할을 수행하기도 하는데, 대표적으로 <strong>서버(server)</strong>와 <strong>클라이언트(client)</strong>가 이다.
  </li>
    <ul>
      <li>
        <strong>서버(server)</strong>는 어떠한 서비스를 제공하는 호스트이다.
      </li>
        <ul>
          <li>
            서버는 파일(파일 서버), 웹 페이지(웹 서버), 메일(메일 서버) 등 다양한 서버가 될 수 있다.
          </li>
          <li>
            서버라는 용어는 serve에서 비롯되었다.
          </li>
        </ul>
      <li>
        <strong>클라이언트(client)</strong>란 서버에 어떠한 요청을 서비스를 요청하고 서버의 응답을 제공받는 호스트이다.
      </li>
        <ul>
          <li>
            클라이언트는 서버에 <strong>요청(request)</strong>을 보내고 그에 대한 <strong>응답(response)</strong>을 제공받는다.
          </li>
        </ul>
    </ul>
</ul>

<h3>2-1-2. 네트워크 장비</h3>
<ul>
  <li>
    네트워크 노드에는 호스트 외에도 호스트간 주고받을 정보가 중간에 거치는 노드들도 있으며 이런 노드들을 <strong>중간 노드</strong>라 한다.
  </li>
    <ul>
      <li>
        대표적으로는 앞으로 학습할 허브, 스위치, 라우터, 공유기 등이 있다.
      </li>
      <li>
        도서에서는 이러한 중간 노드들을 <strong>네트워크 장비</strong>라 통칭한다.
      </li>
      <li>
        네트워크 장비는 호스트 간 주고받는 정보가 원하는 수신지까지 안정적이고 안전하게 전송될 수 있도록 한다.
      </li>
    </ul>
</ul>

<h4>호스트, 네트워크 장비, 서버, 클라이언트는 완전히 배타적인 개념일까요?</h4>
<ul>
  <li>
    네트워크 노드의 분류는 역할에 따라 분류를 한 것일뿐이다.
  </li>
  <li>
    따라서 호스트와 네트워크 장비로 나뉠 수 있지만 이 둘 모두를 수행할 수도 있다.
  </li>
  <li>
    서버와 클라이언트 또한 역할에 따른 구분일 뿐 둘 모두의 역할을 수행할 수 있다.
  </li>
  <li>
    핵심은 다음 두 가지이다.
  </li>
    <ul>
      <li>
        호스트 역할을 수행할 수 있는 노드, 네트워크 장비 역할을 수행할 수 있는 노드가 있다.
      </li>
      <li>
        서버 역할을 수행할 수 있는 노드, 클라이언트 역할을 수행할 수 있는 노드가 있다.
      </li>
    </ul>
</ul>

<h3>2-1-3. 통신 매체</h3>
<ul>
  <li>
    그래프는 노드, 그리고 노드를 연결 짓는 간선(링크)으로 이루어지기 때문에 호스트와 네트워크 장비 또한 <strong>유무선 매체</strong>를 통해 <strong>연결</strong>되어 있어야 한다.
  </li>
  <li>
    각 노드를 연결하는 간선을 <strong>통신 매체</strong>라 한다.
  </li>
    <ul>
      <li>
        통신 매체에는 노드들을 유선으로 연결하는 <strong>유선 매체</strong>, 무선으로 연결하는 <strong>무선 매체</strong>가 있다.
      </li>
    </ul>
</ul>

<h3>2-1-4. 메시지</h3>
<ul>
  <li>
    통신 매체로 연결된 노드가 주고받는 정보를 <strong>메시지(message)</strong>라고 한다.
  </li>
    <ul>
      <li>
        메시지는 웹 페이지, 파일, 메일 등 다양한 형태일 수 있다.
      </li>
    </ul>
  <li>
    정리를 하면 네트워크는 다음의 구성으로 이루어진다.
  </li>
    <ul>
      <li>
        가장자리 노드인 호스트
      </li>
      <li>
        중간 노드인 네트워크 장비
      </li>
      <li>
        노드들을 연결하는 간선인 통신 매체
      </li>
      <li>
        노드들이 주고받는 정보인 메시지
      </li>
    </ul>
</ul>

<br>

<h2>2-2. 범위에 따른 네트워크 분류</h2>
<ul>
  <li>
    호스트가 메시지를 주고받는 범위는 일반 가정이 될 수도 있고, 기업, 때로는 도시나 국가 등 <strong>네트워크 구성 범위는 다양</strong>하다.
  </li>
  <li>
    네트워크는 범위에 따라 크게 <strong>LAN</strong>과 <strong>WAN</strong>으로 구분한다.
  </li>
</ul>

<h3>2-2-1. LAN</h3>
<ul>
  <li>
    <strong>LAN</strong>은 <strong>Local Area Network의 약자</strong>로 이름 그대로 <strong>가까운 지역</strong>을 연결한 근거리 통신망을 의미한다.
  </li>
    <ul>
      <li>
        가정, 기업, 학교 등 한정된 공간에서의 네트워크가 해당한다.
      </li>
    </ul>
</ul>

<h3>2-2-2. WAN</h3>
<ul>
  <li>
    <strong>WAN</strong>은 <strong>Wide Area Network의 약자</strong>로 <strong>먼 지역을 연결</strong>하는 광역 통신망을 의미한다.
  </li>
  <li>
    멀리 떨어진 LAN을 연결할 수 있는 네트워크가 WAN이다.
  </li>
    <ul>
      <li>
        LAN을 연결하는 것은 네트워크끼리의 연결을 의미하기에 WAN은 네트워크의 네트워크이다. 따라서 <strong>인터넷은 WAN으로 분류</strong>된다.
      </li>
      <li>
        즉 같은 LAN에 속한 호스트끼리 메시지를 주고받을 때는 인터넷 연결과 같은 WAN이 필요 없지만, 다른 LAN에 속한 호스트와 메시지를 주고받기 위해서는 WAN이 필요하다.
      </li>
    </ul>
  <li>
    우리가 인터넷을 사용하기 위해 접속하는 WAN은 <strong>ISP(Internet Service Provider)</strong>라는 인터넷 서비스 업체가 구축하고 관리한다.
  </li> 
    <ul>
      <li>
        ISP는 사용자에게 인터넷과 같은 WAN에 연결 가능한 회선을 임대하는 등 WAN과 관련된 다양한 서비스를 제공한다.
      </li>
      <li>
        인터넷을 사용하기 위해 ISP와 계약하여 인터넷 사용 요금을 지불하는 이유도 위와 같은 이유 때문이다.
      </li>
    </ul>
  <li>
    인터넷이 WAN의 전부는 아니며 멀리 떨어진 LAN을 연결하기 위해 특정 조직에서 불특정 다수에게 공개되지 않은 WAN을 구축할 수도 있다.
  </li>
</ul>

<h4>CAN과 MAN</h4>
<ul>
  <li>
    LAN과 WAN을 더 세밀하게 나누면 LAN보다는 넓고 WAN보다는 좁은 대표적인 네트워크로 CAN과 MAN이 있다.
  </li>
  <li>
    <strong>CAN(Campus Area Network)</strong>은 학교 또는 회사의 여러 건물 단위로 연결되는 규모의 네트워크를 의미한다.
  </li>
  <li>
    <strong>MAN(Metropolitan Area Network)</strong>은 도시나 대도시 단위로 연결되는 규모의 네트워크를 의미한다.
  </li>
  <li>
    정리를 하면 <strong>WAN > MAN > CAN > LAN</strong>순으로 작아진다고 볼 수 있다.
  </li>
</ul>
