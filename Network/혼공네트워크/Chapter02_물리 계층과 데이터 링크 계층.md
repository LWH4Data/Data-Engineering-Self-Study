<h1>1. 이더넷</h1>
<ul>
  <li>
    물리 계층과 데이터 링크 계층은 <strong>이더넷</strong>이라는 공통된 기술이 사용되기 때문에 서로 밀접하게 연관되어 있다.
  </li>
  <li>
    <strong>이더넷(Ethernet)</strong>은 현대 LAN, 특히 <strong>유선 LAN 환경</strong>에서 가장 대중적으로 사용되는 기술이다.
  </li>
    <ul>
      <li>
        예를 들어 두 대의 컴퓨터가 있다면 서로 정보를 주고받기 위해서는 먼저 <strong>케이블과 같은 통신 매체</strong>가 필요하고 통신 매체를 통해 <strong>정보를 송수신하는 방법</strong>이 정해져 있어야 한다.
      </li>
    </ul>
  <li>
    따라서 이더넷은 통<strong>신 매체의 규격</strong>들과 <strong>송수신되는 프레임의 형태, 프레임을 주고받는 방법 등</strong>이 정의된 네트워크 기술이다.
  </li>
</ul>

<br>

<h2>1-1. 이더넷 표준</h2>
<ul>
  <li>
    오늘날 유선 LAN 환경은 대부분 <strong>이더넷</strong>을 기반으로 구성된다.
  </li>
    <ul>
      <li>
        LAN 환경을 구축했다면 물리 계층과 데이터 링크 계층에서 주고받는 프레임은 십중팔구 이더넷 프레임의 형식을 따를 것이다.
      </li>
    </ul>
  <li>
    이더넷은 국제적으로 표준화가 되었으며 처음 등장한 이후 전기전자공학자협회(IEEE; Institute of Electrical and Electronics Engineers)라는 국제 조직은 관련 기술을 <strong>IEEE 802.3</strong>이라는 이름으로 표준화하였다.
  </li>
    <ul>
      <li>
        IEEE 802.3은 이더넷 관련 다양한 표준들의 모음을 의미한다고 생각할 수 있다.
      </li>
      <li>
        서로 다른 컴퓨터가 각기 다른 제조사의 네트워크 장비를 사용해도 동일한 형식의 프레임을 주고받을 수 있는 것도 이 덕이다.
      </li>
      <li>
        IEEE는 이더넷 작업 그룹(Ethernet working group)의 이름이기도 하며 관련 홈페이지에는 현제도 새로운 표준이 개발되고 있다.
      </li>
    </ul>
  <li>
    이더넷의 표준들은 802.3u 혹은 802.3ab와 같이 <strong>버전을 나타내는 알파벳</strong>으로 표현한다.
  </li>
  <li>
    핵심은 <strong>이더넷 표준</strong>에 따라 지원되는 네트워크 장비, 통신 매체의 전송 속도 등이 달라질 수 있다는 것이다.
  </li>
</ul>

<br>

<h2>1-2. 통신 매체 표기 형태</h2>
<ul>
  <li>
    일반적으로 이더넷 표준 규격에 따라 구현된 통신 매체를 지칭할 때에는 <strong>통신 매체의 속도와 특성</strong>을 한눈에 파악하기 위해 <strong>'전송 속도 BASE-추가특성'</strong>과 같은 형태로 표기한다.
  </li>
     <ul>
       <li>
         예를 들면 1000BASE-sx, 5GBASE-T, 1000BASE-LX 등 이다.
       </li>
     </ul>
  <li>
    <strong>전송 속도(data rate)</strong>는 숫자만 표기되어 있으면 Mbps, 숫자 뒤에 G가 붙으면 Gbps를 의미한다.
  </li>
  <li>
    <strong>BASE</strong>는 베이스밴드(BASEband)의 약자로 변조 타입(modulation type)을 의미한다.
  </li>
    <ul>
      <li>
        변조 타입이란 비트 신호로 변환된 데이터를 <strong>통신 매체로 전송하는 방법</strong>을 의미한다.
      </li>
      <li>
        일반적인 LAN 환경에서는 특별한 경우가 아니라면 대부분 디지털 신호를 송수신하는 베이스밴드 방식을 이용한다.
      </li>
        <ul>
          <li>
            예를 들면 BASE 외에 BROAD로 표기하는 브로드밴드(BROADband), PASS로 표기하는 패스밴드(PASSband)도 있다.
          </li>
        </ul>
    </ul>
  <li>
    <strong>추가 특성(additional distinction)</strong>에는 통신 매체의 특성을 명시한다.
  </li>
    <ul>
      <li>
        예를 들어 10BASE-2, 10BASE-5와 같이 <strong>전송 가능한 최대 거리</strong>가 명시되기도 하고, 데이터가 비트 신호로 변환되는 방식을 의미하는 <strong>물리 계층 인코딩 방식</strong>이 명시되기도 하며, 비트 신호를 옮길 수 있는 전송로 수를 의미하는 <strong>레인 수</strong>가 명시되기도 한다.
      </li>
    </ul>
</ul>

<br>

<h2>1-3. 통신 매체 종류</h2>
<ul>
  <li>
    대중적인 통신 매체로는 추가 특성으로 C, T, S, L이 있다.
  </li>
    <ul>
      <li>
        C: 동축 케이블
      </li>
      <li>
        T: 트위스티드 페어 케이블
      </li>
      <li>
        S: 단파장 광섬유 케이블
      </li>
      <li>
        L: 장파장 광섬유 케이블
      </li>
    </ul>
  <li>
    통신 매체 표기 형식의 예를 들면 다음과 같다.
  </li>
    <ul>
      <li>
        10BASE-T 케이블: 10Mbps 속도를 지원하는 트위스티드 페어 케이블
      </li>
      <li>
        1000BASE-SX 케이블: 1000Mbps 속도를 지원하는 단파장 광섬유 케이블
      </li>
      <li>
        1000BASE-LX 케이블: 1000Mbps 속도를 지원하는 장파장 광섬유 케이블
      </li>
    </ul>
  <li>
    이더넷 표준과 통신 매체의 표기를 표와 같이 볼 수 있다 (p81).
  </li>
    <ul>
      <li>
        항상 일대일로 대응되는 것은 아니다.
      </li>
    </ul>
</ul>

<h4>이더넷의 발전</h4>
<ul>
  <li>
    이더넷은 지금도 발전하는 중이며 초기에는 대체로 10Mbps 였으나 100Mbps로 발전하였고 이를 고속 이더넷(Fast Ethernet)이라고도 한다.
  </li>
    <ul>
      <li>
        100Mbps 다음으로도 1Gbps, 10Gbps 등이 있다.
      </li>
    </ul>
</ul>

<br>

<h2>1-4. 이더넷 프레임</h2>
<ul>
  <li>
    데이터 링크 계층의 이더넷 프레임을 알아본다.
  </li>
  <li>
    현대 유선 LAN 환경은 대부분 이더넷을 기반으로 구성되기 때문에 이더넷 네트워크에서 주고받는 프레임인 <strong>이더넷 프레임(Ethernet frame)</strong> 형식은 정해져 있다.
  </li>
  <li>
    이더넷 프레임은 상위 계층으로부터 받아들인 정보에 헤더와 트레일러를 추가하는 <strong>캡슐화 과정</strong>을 통해 만들어진다.
  </li>
    <ul>
      <li>
        수신기 입장에서는 프레임의 헤더와 트레일러를 제거한 뒤 상위 계층으로 올려보내는 <strong>역캡슐화</strong> 과정을 거친다.
      </li>
    </ul>
  <li>
    이더넷 프레임 헤더는 기본적으로 '프리앰블(8바이트)-주신지 MAC 주소(6바이트)-송신지 MAC 주소(6바이트)-타입/길이(2바이트)-데이터(45 ~ 1500 바이트)-FCS(4바이트)'로 구성된다 (p82).
  </li>
</ul>

<h3>1-4-1. 프리앰블</h3>
<ul>
  <li>
    프리앰블(preamble)은 <strong>이더넷 프레임의 시작</strong>을 알리는 8바이트(64비트) 크기의 정보이다.
  </li>
  <li>
    프리앰블의 첫 7바이트는 <strong>10101010</strong> 값을 가지고, 마지막 바이트는 <strong>10101011</strong> 값을 가진다.
  </li>
    <ul>
      <li>
        수신지는 이 프리앰블을 통해 이더넷 프레임이 오고 있음을 감지한다.
      </li>
    </ul>
</ul>

<h3>1-4-2. 수신지 MAC 주소와 송신지 MAC 주소</h3>
<ul>
  <li>
    가장 중요한 부분이며 물리적 주소로도 불리는 MAC 주소는 데이터 링크 계층의 핵심이다.
  </li>
    <ul>
      <li>
        MAC 주소는 네트워크 인터페이스마다 부여되는 6바이트(48비트) 길이의 주소로, LAN 내의 수신지와 송신지를 특정할 수 있다.
      </li>
      <li>
        MAC 주소는 일반적으로 겹치지 않도록 고유하면서 변경되지 않는 주소로써 네트워크 인터페이스마다 부여된다. (변경하는 경우도 있다).
      </li>
    </ul>
  <li>
    보통 NIC(Network Interface Controller)가 여러 개 있다면 MAC 주소도 여러 개 있을 수 있다.
  </li>
</ul>

<h3>1-4-3. 타입/길이</h3>
<ul>
  <li>
    타입/길이 필드에는 <strong>타입(type)</strong> 혹은 <strong>길이(length)</strong>가 올 수 있다.
  </li>
    <ul>
      <li>
        필드에 명시된 크기가 1500(16진수 05DC) 이하일 경우 프레임의 크기(길이)를 나타낸다.
      </li>
      <li>
        1536(16진수 0600) 이상일 경우 타입을 나타내는 데 사용된다.
      </li>
    </ul>
  <li>
    타입이란 이더넷 프레임이 <strong>'어떤 정보를 캡슐화했는지'</strong>를 나타내는 정보이며 <strong>이더타입(ethertype)</strong>이라고도 부른다.
  </li>
    <ul>
      <li>
        대표적으로 상위 계층에서 사용된 프로토콜의 이름이 명시된다.
      </li>
      <li>
        예를 들어 16진수 0800이라면 IPv4 프로토콜이, 16진수 0806이라면 ARP 프로토콜이 캡슐화된 정보를 운반하는 것이다.
      </li>
    </ul>
</ul>

<h3>1-4-4. 데이터</h3>
<ul>
  <li>
    데이터는 상위 계층에서 전달받거나 상위 계층으로 전달해야 할 내용이다.
  </li>
    <ul>
      <li>
        네트워크 계층의 데이터와 헤더를 합친 PDU가 포함된다.
      </li>
      <li>
        최대 크기는 1500바이트로, 유의할 점은 반드시 일정 크기(46바이트 이상)여야 한다. 크기가 충족되지 못하는 경우 <strong>패딩(padding)</strong>이라는 정보가 내부에 채워진다.
      </li>
    </ul>
</ul>

<h3>1-4-5.FCS</h3>
<ul>
  <li>
    FCS(Frame Check Sequence)는 <strong>수신한 이더넷 프레임에 오류가 있는지</strong> 확인하기 위한 필드이다.
  </li>
    <ul>
      <li>
        데이터 링크 계층에서 오류 검출이 이루어지는 영역이 해당한다.
      </li>
    </ul>
  <li>
    FCS 필드에는 CRC(Cyclic Redundancy Check, 순환 중복 검사)라고 불리는 오류 검출용 값이 들어간다.
  </li>
    <ul>
      <li>
        송신지는 프리앰블을 제외한 나머지 필드 값들을 바탕으로 <strong>CRC 값을 계산</strong>한 후 해당 값을 FCS 필드에 명시한다.
        <br>&rarr; 수신지에서는 수신한 프레임에서 프리앰블과 FCS 필드를 제외한 나머지 필드 값들을 바탕으로 CRC 값을 계산하고 <strong>FCS 필드의 값과 비교</strong>한다.
        <br>&rarr; 비교 값이 <strong>일치하지 않으면 프레임에 오류</strong>가 있다 판단하고 프레임을 폐기한다.
      </li>
    </ul>
</ul>

<h4>토큰 링</h4>
<ul>
  <li>
    이더넷 외에 다른 LAN 기술로 대표적으로는 <strong>토큰 링(Token Ring)</strong> 방식이 있다.
  </li>
    <ul>
      <li>
        토큰 링 네트워크에서는 호스트들이 <strong>링(고리)형태</strong>로 연결된다.
      </li>
      <li>
        네트워크 내 다른 호스트에게 메시지를 송신하려면 반드시 토큰을 가지고 있어야 한다.
      </li>
    </ul>
  <li>
    토큰은 순차적으로 송신을 하면 다음 호스트에게 넘겨 주며 순환한다.
  </li>
</ul>

<br><br>

<h1>2. NIC와 케이블</h1>
<ul>
  <li>
    NIC(Network Interface Controller)는 호스트와 통신 매체를 연결하고, MAC 주소가 부여되는 네트워크 장비이다.
  </li>
  <li>
    케이블(cable)은 NIC에 연결되는 물리 계층의 유선 통신 매체이다.
  </li>
    <ul>
      <li>
        케이블의 종류는 다양하지만 오늘날 주로 사용되는 케이블의 두 종류는 <strong>트위스티드 페어 케이블</strong>과 <strong>광섬유 케이블</strong>이다.
      </li>
    </ul>
  <li>
    NIC와 케이블은 호스트뿐만 아니라 네트워크 장비에도 연결될 수 있지만 도서에서는 편의상 호스트와 연결된라고 표현한다.
  </li>
</ul>

<br>

<br>

<h2>2-1. NIC</h2>
<ul>
  <li>
    호스트와 유무선 <strong>통신 매체를 연결</strong>하고 컴퓨터가 이해할 수 있도록 <strong>정보 간 변환</strong>을 담당하는 장비가 NIC이다.
  </li>
  <li>
    NIC는 호스트의 귀와 입과 같다고 볼 수 있으며 이런 점에서 NIC를 <strong>호스트를 네트워크(LAN)에 연결하기 위한 하드웨어</strong>라고 표현하기도 한다.
  </li>
</ul>

<h3>2-1-1. NIC의 생김새</h3>
<ul>
  <li>
    NIC는 네트워크 인터페이스 카드, 네트워크 어댑터, LAN 카드, 네트워크 카드, 이더넷 카드 등 다양한 명칭으로 불린다.
  </li>
    <ul>
      <li>
        카드라는 표현이 붙은 이유는 초기 NIC는 확장 카드 형태로 연결해서 사용했기 때문이다.
      </li>
    </ul>
  <li>
    최근에는 USB로 연결하는 NIC도 있고, 마더보드에 내장된 NIC 등 다양한 종류가 존재한다.
  </li>
    <ul>
      <li>
        추가 장치 없이 네트워크에 연결이 가능하다면 높은 확률로 마더보드에 내장된 NIC를 사용 중인 것이다.
      </li>
    </ul>
</ul>

<h3>2-1-2. NIC의 역할</h3>
<ul>
  <li>
    NIC는 통신 매체에 흐르는 신호를 <strong>호스트가 이해하는 프레임</strong>으로 변환하거나 반대로 호스트가 이해하는 프레임을 <strong>통신 매체에 흐르는 신호</strong>로 변환한다.
  </li>
  <li>
    NIC는 네트워크와의 연결점을 담당한다는 점에서 <strong>네트워크 인터페이스(network interface)</strong>역할을 수행한다고도 한다.
  </li>
  <li>
    NIC는 MAC 주소를 통해 <strong>자기 주소</strong>와 수신되는 프레임의 <strong>수신지 주소</strong>를 인식한다.
  </li>
    <ul>
      <li>
        어떤 프레임이 도달했을 때 자신과 관련 없는 수신지 MAC 주소가 명시된 프레임이라면 폐기할 수 있다.
      </li>
      <li>
        FCS 필드를 토대로 오류를 검출해 잘못된 프레임을 폐기할 수도 있다.
      </li>
    </ul>
</ul>

<h4>NIC의 지원 속도</h4>
<ul>
  <li>
    NIC는 지원되는 속도가 모두 다르며 따라서 네트워크 속도에 맞는 NIC를 쓰는 것이 중요하다. 많은 트래픽을 담당하는 서버와 같은 경우 그게 맞는 NIC를 사용해야한다.
  </li>
  <li>
    NIC의 지원 속도는 10Mbps부터 100Gbps까지 다양하다.
  </li>
</ul>

<br>

<h2>2-2. 트위스티드 페어 케이블</h2>
<ul>
  <li>
    통신 매체의 속도가 느리다면 연결된 호스트의 속도가 아무리 빠르더라도 의미가 없다.
  </li>
  <li>
    <strong>트위스티드 페어 케이블(twisted pair cable)</strong>은 <strong>구리 선</strong>으로 전기 신호를 주고받는 통신 매체이다.
  </li>
    <ul>
      <li>
        LAN 케이블이라고 하면 가장 먼저 떠오를 만큼 대중적인 케이블 중 하나이다.
      </li>
    </ul>
</ul>

<h3>2-2-1. 트위스티드 페어 케이블의 생김새</h3>
<ul>
  <li>
    트위스티드 페어 케이블은 <strong>케이블 본체</strong>와 케이블의 연결부인 <strong>커넥터(connector)</strong>로 이루어져 있다.
  </li>
  <li>
    보통 공유기나 컴퓨터에 인터넷 선을 연결한다면 선 끝에 연결을 하는 장치인 <strong>커넥터</strong>가 있다. 트위스티드 페어 케이블에서 주로 활용되는 커넥터를 <strong>RJ-45</strong>라 한다.
  </li>
  <li>
    케이블 본체 내부에는 트위스티드라는 이름처럼 구리 선이 <strong>두 가닥씩(pair) 꼬아(twisted)</strong>져 있다.
  </li>
  <li>
    본체가 구리 선으로 이루어진 상태에서 전기 신호를 주고받다 보면 구리 선에 <strong>전자적 간섭</strong>이 생길 수 있고 이로 인해 발생하는 전기 신호를 왜곡시킬 수 있는 간섭을 <strong>노이즈(noise)</strong>라고 한다.
  </li>
  <li>
    노이즈의 문제로 트위스티드 페어 케이블 중에서는 구리 선을 그물 모양의 철사 또는 포일로 감싸 보호하는 경우가 있다.
  </li>
    <ul>
      <li>
        구리 선 주변을 감싸 노이즈를 감소시키는 방식을 <strong>차폐(shielding)</strong>라고 한다.
      </li>
      <li>
        이때 그물 모양의 철사를 <strong>브레이드 실드(braided sheild)</strong>, 포일로 감싸는 방법을 <strong>포일 실드(foil sheild)</strong>라고 한다.
      </li>
    </ul>
</ul>

<h3>2-2-2. 실드에 따른 트위스티드 페어 케이블의 분류</h3>
<ul>
  <li>
    브레이드 실드로 구리 선을 감싸 노이즈를 감소시킨 트위스티드 페어 케이블은 <strong>STP(Sheilded Twisted Pair) 케이블</strong>, 포일 실드로 노이즈를 감소시킨 트위스티드 페어 케이블은 <strong>FTP(Foil Twisted Pair)</strong> 케이블이라 한다.
  </li>
  <li>
    아무것도 감싸지 않은 구리 선만 있는 케이블은 <strong>UTP(Unshielded Twisted Pair) 케이블</strong>이라 한다.
  </li>
  <li>
    트위스티드 페어 케이블을 STP, FTP, UTP 등 실드에 따라 크게 세 종류로 나눌 수도 있지만 xx/YTP 등으로 <strong>표기로 더 세분화</strong>해서 나눌 수도 있다.
  </li>
    <ul>
      <li>
        X와 Y에는 U, S, F로 UTP, STP, FTP가 표기된다.
      </li>
        <ul>
          <li>
            S/FTP 케이블: 외부는 브레이드 실드로 보호되고, 꼬인 구리 선 쌍은 포일 실드로 간싼 케이블을 의미한다.
          </li>
          <li>
            F/FTP 케이블: 케이블 외부와 각 구리 선 쌍을 모두 포일 실드로 감싼다.
          </li>
          <li>
            SF/FTP 케이블: 케이블 외부는 브레이드 실드와 포일 실드로 감싸고, 각 구리 선 쌍은 포일 실드로 감싼다.
          </li>
          <li>
            U/UTP 케이블: 아무것도 감싸지 않는다.
          </li>
        </ul>
    </ul>
  <li>
    실드의 종류는 케이블 본체에 명시되기 때문에 암기할 필요는 없다.
  </li>
</ul>

<h3>2-2-3. 카테고리에 따른 트위스티드 페어 케이블의 분류</h3>
<ul>
  <li>
    트위스티드 페어 케이블은 <strong>카테고리(Category)</strong>에 따라 페어 케이블 <strong>성능의 등급을 구분</strong>하는 역할을 한다.
  </li>
    <ul>
      <li>
        높은 카테고리에 속한 케이블일수록 높은 성능을 보인다.
      </li>
      <li>
        카테고리는 Category의 앞 글자를 따와 <strong>Cat</strong>이라는 표기로 줄여서 표현하는 경우가 많으며 보통 예를 들어 카테고리 3이라면 Cat3이라고 표기한다.
      </li>
      <li>
        카테고리표는 p94에서 확인할 수 있다.
      </li>
    </ul>
</ul>

<br>

<h2>2-3. 광섬유 케이블</h2>
<ul>
  <li>
    <strong>광섬유 케이블(fiber optic cable)</strong>은 빛(광신호)을 이용해 정보를 주고받는 케이블이다.
  </li>
    <ul>
      <li>
        빛을 이용하기 때문에 전기 신호에 비하여 속도가 빠르고, 먼 거리까지 전송이 가능하며, 노이즈로부터 간섭받는 영향도 적다.
      </li>
      <li>
        위와 같은 이유로 광섬유 케이블은 대륙 간 네트워크 연결에도 사용된다.
      </li>
    </ul>
</ul>

<h3>2-3-1. 광섬유 케이블의 생김새</h3>
<ul>
  <li>
    광섬유 케이블 또한 트위스티드 페어 케이블과 마찬가지로 본체와 커넥터로 이루어져 있지만, 트위스트 페어 <strong>케이블에 비해 커넥터의 종류가 더 다양</strong>하다.
  </li>
    <ul>
      <li>
        대표적인 커넥터 종류로 LC 커넥터, SC 커넥터, FC 커넥터, ST 커넥터가 있다.
      </li>
      <li>
        광섬유는 빛을 운반하는 매체이다.
      </li>
    </ul>
  <li>
    광섬유의 중심에는 <strong>코어(core)</strong>가 있으며 실질적으로 <strong>빛이 흐르는 부분</strong>이다.
  </li>
    <ul>
      <li>
        코어를 둘러싸는 것으로는 <strong>클래딩(cladding)</strong>이 있다. 클래딩은 빛이 코어 안에서만 흐르도록 <strong>빛을 가두는 역할</strong>을 한다.
      </li>
        <ul>
          <li>
            코어와 클래딩 간의 빛의 굴절률 차이를 만들어 빛을 코어 내부에 가두는 원리이다.
          </li>
        </ul>
    </ul>
  <li>
    광섬유 케이블은 가장 기본적인 기준으로 <strong>코어의 지름</strong>에 따라 <strong>싱글 모드 광섬유 케이블(SMF; Single Mode Fiber)</strong>과 <strong>멀티 모드 광섬유 케이블(MMF; Multi Mode Fiber)</strong>로 나뉜다.
  </li>
</ul>

<h3>2-3-2. 싱글 모드 광섬유 케이블</h3>
<ul>
  <li>
    싱글 모드 광섬유 케이블은 코어의 지름이 8 ~ 10 마이크로미터 정도이다. (머리카락이 50~150 마이크로미터임).
  </li>
  <li>
    코어의 지름이 작다면 빛이 이동할 수 있는 경로가 적고, 이때 빛의 이동 경로가 하나 이상을 갖기 어렵기에 <strong>'모드(mode)가 하나(single)'</strong>라고 표현한다.
  </li>
  <li>
    싱글 모드 케이블은 <strong>신호 손실이 적어 장거리 전송</strong>에 적합하지만, 멀티 모드에 비해 일반적으로 <strong>비용이 높다</strong>는 단점이 있다.
  </li>
  <li>
    싱글 모드 케이블은 파장이 긴 <strong>장파장의 빛</strong>을 사용한다. 
  </li>
    <ul>
      <li>
        대표적인 광섬유 케이블 규격으로는 1000BASE-LX, 10GBASE-LR이 있으며 L은 장(long) 파장을 의미한다.
      </li>
    </ul>
  <li>
    싱글 모드 광섬유 케이블의 본체는 대부분 <strong>노란색</strong>과 <strong>파란색</strong>이다.
  </li>
</ul>

<h3>2-3-3. 멀티 모드 광섬유 케이블</h3>
<ul>
  <li>
    멀티 모드 케이블은 코어의 지름이 50 ~ 62.5 마이크로미터로 싱글 모드보다 크며 여러 경로롤 이동할 수 있다. 이를 두고 <strong>'모드(mode)가 여러 개(multi)'</strong>라고 한다.
  </li>
  <li>
    멀티 모드는 싱글 모드보다 전송 시 <strong>신호 손실</strong>이 클 수 있어 장거리 전송에는 부적합하며 <strong>근거리 연결에 적합</strong>하다.
  </li>
  <li>
    멀티 모드 케이블은 싱글 모드에 비해 <strong>단파장의 빛</strong>을 사용한다.
  </li>
    <ul>
      <li>
        대표적인 멀티 모드 케이블 규격으로는 1000BASE-SX, 10GBASE-SR이 있으며 S는 단(short)파장을 의미한다.
      </li>
    </ul>
  <li>
    멀티 모드 광섬유 케이블은 <strong>오랜지색</strong>과 <strong>아쿠아색</strong>을 띈다.
  </li>
</ul>

<br><br>

<h1>3. 허브</h1>
<ul>
  <li>
    통신 매체를 통해 수신되는 메시지는 다른 호스트에게 전달되는 과정에서 네트워크 장비를 거칠 수 있는데 대표적인 네트워크 장비로는 <strong>물리 계층</strong>에는 <strong>허브</strong>가 있고, <strong>데이터 링크 계층</strong>에는 <strong>스위치</strong>가 있다.
  </li>
  <li>
    물리 계층에서 여러 대의 호스트를 연결하는 허브의 특징과 이와 관련된 동작 방식인 <strong>반이중</strong>, 그리고 반대되는 개념인 <strong>전이중</strong> 모드 통신을 학습힌다.
  </li>
  <li>
    허브에서 발생하는 충돌 문제를 해결하기 위한 프로토콜인 <strong>CSMA/CD</strong>를 학습힌다.
  </li>
</ul>

<br>

<h2>3-1. 주소 개념이 없는 물리 계층</h2>
<ul>
  <li>
    <strong>물리 계층</strong>에는 주소 개념이 없고, 송수신지를 특정할 수 있는 주소는 <strong>데이터 링크 계층</strong>부터 존재한다.
  </li>
  <li>
    물리 계층은 <strong>통신 매체상의 송수신</strong>이 이루어질 뿐 송수신되는 정보에 대한 어떠한 조작(송수신 내용 변경)이나 판단을 하지 않는다.
  </li>
  <li>
    데이터 링크 계층에는 <strong>주소 개념</strong>이 있으며 MAC 주소가 여기 속한다.
  </li>
    <ul>
      <li>
        데이터 링크 계층을 포함한 그 이상의 계층 장비들은 <strong>송수신지를 특정</strong>할 수 있고, 주소를 바탕으로 <strong>송수신되는 정보에 대한 조작과 판단</strong>을 할 수 있다.
      </li>
    </ul>
</ul>

<br>

<h2>3-2. 허브</h2>
<ul>
  <li>
    물리 계층의 <strong>허브(hub)</strong>는 <strong>여러 대의 호스트를 연결</strong>하는 장치이다.
  </li>
    <ul>
      <li>
        리피터 허브(repeter hub)라 부르기도 한다.
      </li>
      <li>
        이더넷 네트워크의 허브는 이더넷 허브(Ethernet hub)라고도 부른다.
      </li>
    </ul>
  <li>
    허브에서 각 커넥터를 연결할 수 있는 부분을 <strong>포트(port)</strong>라고 한다. 포트에는 호스트와 연결된 통신 매체를 연결할 수 있다.
  </li>
</ul>

<h3>3-2-1. 허브의 특징</h3>
<ul>
  <li>
    허브는 오늘날 인터넷 환경에서 잘 사용되지 않지만 두 가지 큰 특징으로 인해 네트워크에서 빠지지 않고 다룬다.
  </li>
    <ol>
      <li>
        첫째, 전달받은 신호를 다른 모든 포트로 그대로 다시 내보낸다.
      </li>
        <ul>
          <li>
            허브는 물리 계층에 속하기 때문에 <strong>주소 개념이 없어</strong> 신호를 받으면 어떠한 조작이나 판단을 하지 않고 <strong>송신지를 제외한 모든 포트에 그저 보내기만</strong> 한다.
          </li>
          <li>
            허브를 통해 신호를 전달받은 모든 호스트는 <strong>데이터 링크 계층에서 패킷의 MAC 주소를 확인</strong>하고 자신과 관련이 없다면 폐기한다.
          </li>
        </ul>
      <li>
        둘째, 반이중 모드로 통신한다.
      </li>
        <ul>
          <li>
            <strong>반이중(half duplex) 모드</strong>는 1차선 도로와 같이 <strong>송수신을 번갈아 가면서 하는 통신 방식</strong>이다.
          </li>
            <ul>
              <li>
                따라서 동시 송수신이 불가능하며 다른 쪽의 전송이 끝나야 사용이 가능하다.
              </li>
            </ul>
          <li>
            <strong>전이중(full duplex) 모드</strong>는 송수신을 동시에 <strong>양방향</strong>으로 할 수 있는 통신 방식이다.
          </li>
        </ul>
    </ol>
</ul>

<h4>리피터</h4>
<ul>
  <li>
    허브 외에 물리 계층의 대표적인 장비로 <strong>리피터(repeater)</strong>가 있다. 리피턴는 전기 신호가 감소하거나 왜곡되는 것을 방지하기 위해 <strong>전기 신호를 증폭</strong>시켜 주는 장비이다.
  </li>
    <ul>
      <li>
        예를 들어 트위스티드 페어 케이블에서 전송 거리가 길어 전기 신호가 감소하거나 왜곡되는 것을 방지한다.
      </li>
    </ul>
  <li>
    리피터는 물리 계층의 장비로 신호에 어떠한 판단이나 조작을 하지 않고 그저 신호를 증폭시키기만한다.
  </li>
  <li>
    허브는 리피터의 기능을 포함하는 경우가 많다.
  </li>
</ul>

<h3>3-2-2. 콜리전 도메인</h3>
<ul>
  <li>
    허브는 반이중 통신을 지원하기 때문에 한 호스트가 허브에 송신하는 동안 다른 호스트는 대기를 해야한다. 이때 동시에 허브에 신호를 송신하면 <strong>충돌(collision)</strong>이 발생한다.
  </li>
  <li>
    충돌이 발생할 수 있는 영역을 <strong>콜리전 도메인(collision domain)</strong>이라고 하며 <strong>허브에 연결된 모든 호스트</strong>는 같은 콜리전 도메인에 속한다.
  </li>
  <li>
    콜리전 도메인은 작으면 작을수록 좋으며 이런 콜리전 도메인으로 인한 충돌 문제를 해결하기 위해서는 <strong>CSMA/CD 프로토콜</strong>을 사용하거나 <strong>스위칭 장비</strong>를 사용해야 한다.
  </li>
</ul>

<br>

<h2>3-3. CSMA/CD</h2>
<ul>
  <li>
    CSMA/CD는 반이중 이더넷 네트워크에서 총돌을 방지하는 대표적인 프로토콜이다.
  </li>
  <li>
    CSMA/CD는 여러 호스트가 공유하는 통신 매체(media)에 접근(access)할 때 사용 가능한 제어(control) 방식이라는 점에서 <strong>접근 제어(MAC; Media Access Control)</strong> 방법의 일종이라고도 부른다.
  </li>
  <li>
    CSMA/CD는 Carrier Sense Multiple Access with Collision Detection의 약자이다.
  </li>
  <li>
    작동 과정은 <strong>'전송 가능 상태인지 확인 &rarr; 다른 호스트가 전송 중이 아닐 때 메시지 전송 &rarr; 충돌이 발생하면 임의의 시간만큼 대기 후 다시 전송'</strong>으로 진행된다.
  </li>
    <ol>
      <li>
        첫쨰, CS는 Carrier Sense, 캐리어 감지를 의미한다.
      </li>
        <ul>
          <li>
            메시지를 보내기 전에 <strong>현재 통신 매체의 사용 가능 여부</strong>를 검사하는 것을 캐리어 감지(Carrier Sense)라 한다.
          </li>
        </ul>
      <li>
        둘째, MA는 Multiple Access, 다중 접근을 의미한다.
      </li>
        <ul>
          <li>
            캐리어 감지를 하는 데도 두 개 이상의 호스트가 <strong>부득이하게 동시에 네트워크를 사용</strong>하려 할 때가 있으며 복수의 호스트가 네트워크에 접근하려는 상황을 <strong>다중 접근(Multiple Access)</strong>이라 한다.
          </li>
          <li>
            다중 접근 상황에서 충돌이 발생한다.
          </li>
        </ul>
      <li>
        셋째, CD는 Collision Detection, 충돌 검출을 의미한다.
      </li>
        <ul>
          <li>
            충돌이 발생하면 이를 검출하는데, 이를 충돌 검출(Collision Detection)이라 한다.
          </li>
          <li>
            충돌을 감지하면 전송을 중단하고, 충돌을 검출한 호스트는 다른 이들에게 충돌이 발생했음을 알리는 <strong>잼 신호(jam signal)</strong>라는 특별한 신호를 보낸다.
          </li>
            <ul>
              <li>
                이후 임의의 시간 동안 기다린 뒤에 다시 전송한다.
              </li>
            </ul>
        </ul>
    </ol>
</ul>

<br><br>

<h1>4. 스위치</h1>
<ul>
  <li>
    스위치는 호스트는 연결된 포트로만 내보내고, 전이중 모드로 통신한다.
  </li>
  <li>
    스위치가 전달받은 신호를 원하는 포트로만 내보낼 수 있는 것은 스위치가 <strong>MAC 주소</strong>를 학습할 수 있기 때문이다.
  </li>
  <li>
    스위치를 이용하면 논리적으로 LAN을 분리하는 가상의 LAN인 <strong>VLAN</strong>을 구성할 수 있다.
  </li>
</ul>

<br>

<h2>4-1. 스위치</h2>
<ul>
  <li>
    <strong>스위치(switch)</strong>는 데이터 링크 계층의 네트워크 장비로 2계층에서 사용하기에 <strong>L2 스위치(L2 switch)</strong>라고도 부른다.
  </li>
  <li>
    스위치의 여러 포트에는 호스트를 연결할 수 있으며 이 점은 허브와 유사하나 아래와 같은 차이가 있다.
  </li>
    <ul>
      <li>
        스위치는 허브와 달리 <strong>MAC 주소</strong>를 학습해 특정 MAC 주소를 가진 호스트에만 프레임을 전달할 수도 있으며 전이중 모드의 통신을 지원한다.
      </li>
    </ul>
  <li>
    스위치를 이용하면 <strong>포트별로 콜리전 도메인</strong>이 나뉘고, <strong>전이중 모드</strong>로 통신하기 때문에 CSMA/CD 프로토콜이 필요하지 않다.
  </li>
    <ul>
      <li>
        CSMA/CD 프로토콜의 대기 시간이 없어 성능상으로도 이점이 있으며 따라서 오늘날까지 이더넷 네트워크 구성으로 자주 사용된다.
      </li>
    </ul>
  <li>
    데이터 링크 계층 상위 계층에서 사용되는 L3 스위치, L4 스위치 등도 있지만 책에서는 L2 스위치를 지칭하는 것으로 한다.
  </li>
</ul>

<h3>4-1-1. 스위치의 특징</h3>
<ul>
  <li>
    스위치의 가장 중요한 특징은 <strong>MAC 주소 학습(MAC address learning)</strong>으로 호스트의 MAC 주소와의 관계를 기억하는 것이다.
  </li>
  <li>
    스위치는 MAC 주소 학습을 위해 <strong>포트와 연결된 호스트의 MAC 주소 간의 연관 관계</strong>를 메모리 표 형태로 기억하며 이 테이블을 <strong>MAC 주소 테이블(MAC address table)</strong>이라고 부른다.
  </li>
</ul>

<br>

<h2>4-2. MAC 주소 학습</h2>
<ul>
  <li>
    MAC 주소 테이블이 채워지고 스위치가 원하는 수신지가 연뎔된 포트에만 프레임을 보낼 수 있는 건 아래 세 가지 기능을 통해서이다.
  </li>
    <ul>
      <li>
        플러딩
      </li>
        <ul>
          <li>
            처음에는 연결된 정보가 없기 때문에 송신지를 제외한 모든 포트로 프레임을 전송한다.
          </li>
        </ul>
      <li>
        포워딩과 필터링
      </li>
        <li>
          플러딩을 한 후 수신과 송신을 한 개별 호스트의 MAC 주소를 스위치의 테이블에 기록한다.
        </li>
        <li>
          이후부터는 전달 받은 프레임을 어디로 보내고 어디로 내보내지 않을지 결정하는 <strong>필터링(filtering)</strong>이 가능해진다.
        </li>
        <li>
          프레임이 전송될 포트에 실제로 프레임을 내보내는 것을 <strong>포워딩(forwarding)</strong>이라 한다.
        </li>
      <li>
        에이징
      </li>
        <ul>
          <li>
            MAC 주소 테이블에 등록된 특정 포트에서 일정 시간 동안 프레임을 전송받지 못했다면 <strong>해당 항목을 삭제</strong>한다. 이를 <strong>에이징(aging)</strong>이라 한다.
          </li>
        </ul>
    </ul>
</ul>

<h4>브릿지</h4>
<ul>
  <li>
    데이터 링크 계층의 스위치와 유사한 장비로 브리지(bridge)가 있다.
  </li>
  <li>
    브리지는 <strong>네트워크 영역을 구획</strong>하여 콜리전 도메인을 나누거나 네트워크를 확장하는 용도로 사용된다.
  </li>
  <li>
    브리지는 스위치의 기능들도 제공하기 때문에 MAC 주소를 학습하고 특정 호스트가 연결되어 있는 포트로 프레임을 포워딩하거나 필터링할 수 있다.
  </li>
  <li>
    단, 스위치가 브리지보다 보편적으로 사용된다.
  </li>
    <ul>
      <li>
        네트워크 구획 및 확장은 스위치를 통해서도 얼마든지 가능하다.
      </li>
      <li>
        최근 스위치의 기능은 일반적으로 브리지의 기능을 포괄할 뿐만 아니라 더 다양하고 프레임의 처리 성능 면에서도 더 우수하기 때문이다.
      </li>
    </ul>
</ul>

<br>

<h2>4-3. VLAN</h2>
<ul>
  <li>
    스위치의 또 다른 중요한 기능으로 VLAN이 있다. VLAN은 Virtual LAN의 줄임말로 한 대의 스위치로 <strong>가상의 LAN</strong>을 만드는 방법이다.
  </li>
    <ul>
      <li>
        스위치를 이용할 때 호스트 중 메시지를 주고 받을 일이 적거나 브로드캐스트 메시지를 받을 필요가 없어 <strong>굳이 같은 네트워크(LAN)에 속할 필요가 없는 호스트</strong>에 적용된다.
      </li>
    </ul>
  <li>
    VLAN을 구성하면 한 대의 물리적 스위치 내에서도 여러 대의 스위치가(VLAN)이 있는 것처럼 <strong>논리적 단위로 LAN</strong>을 구획할 수 있다.
  </li>
    <ul>
      <li>
        마찬가지로 한 VLAN에 속한 호스트가 브로드캐스트를 하게 되면 다른 VLAN에 속한 호스트에게까지는 전달되지 않는다. (서로 다른 네트워크로 간주하기 때문이다).
      </li>
    </ul>
</ul>

<h3>4-3-1. 포트 기반 VLAN</h3>
<ul>
  <li>
    가장 단순한 방법으로는 스위치의 포트가 VLAN을 결정하는 <strong>포트 기반 VLAN(port based VLAN)</strong>이 있다.
  </li>
    <ul>
      <li>
        사전에 특정 포트에 VLAN을 할당하고, 호스트를 연결한다.
      </li>
    </ul>
  <li>
    하나의 스위치에 여러 개의 VLAN을 할당하는 건 포트가 부족할 수 있고 그렇다고 VLAN 스위치를 여러 대 구비하는 것 또한 포트의 낭비가 된다.
  </li>
  <li>
    위와 같은 문제를 해결하기 위해 <strong>VLAN 트렁킹(VLAN Trunking)</strong>이라는 방법이 존재한다. VLAN 트렁킹은 두 대 이상의 VLAN 스위치를 효율적으로 연결하여 확장한다.
  </li>
    <ul>
      <li>
        스위치 간의 통신을 위한 특별한 포트인 트렁크 포트(trunk port)에 VLAN을 서로 연결한다 (p121).
      </li>
      <li>
        트렁크 포트는 태그 포트(tagged port)라고도 부르며 반면에 하나의 VLAN이 할당된 일반적인 포트는 액세스 포트(access port)라고 한다.
      </li>
    </ul>
</ul>

<h4>트렁크 포트로 전달받은 프레임이 어떤 VLAN에 속하는지 파악하는 방법</h4>
<ul>
  <li>
    트렁크 포트로 전달된 프레임은 아직 학습되지 않은 MAC 주소를 포함하고 있을 경우 일반적인 이더넷 프레임만으로는 알 수 없다.
  </li>
    <ul>
      <li>
        이를 위해 <strong>어떤 VLAN에 속하는지 식별</strong>하기 위한 정보까지 추가된 확장된 이더넷 프레임을 사용하며 이를 <strong>802.1Q 프레임</strong>이라 한다.
      </li>
      <li>
        즉 이더넷 프레임 사이에 <strong>32비트 크기의 VLAN 태크 정보</strong>가 추가된다.
      </li>
    </ul>
</ul>

<h3>4-3-2. MAC 기반 VLAN</h3>
<ul>
  <li>
    사전에 설정된 <strong>MAC 주소</strong>에 따라 VLAN이 결정되는 MAC 기반 VLAN(MAC based VLAN)도 있다.
  </li>
    <ul>
      <li>
        포트가 아닌 송수신하는 프레임 속 MAC 주소가 호스트가 속할 VLAN을 결정하는 방식이다.
      </li>
    </ul>
</ul>
